# 全局导航（T07）

2026-10-19 反馈改进：当前操作以[工作区与导航更新](workspace-input-refresh.md)为准；手动导航已移除。本文保留早期阶段的实现和验证证据；其中单屏限制、手动模式、独立标签页及默认关闭自动接入的描述属于旧版。

2026-10-18。导航与应用操作分开：默认保留应用的鼠标交互；显式进入导航模式后，滚轮与左右键用于画布手势。仅已开始的单屏管理会话可进入导航。

## 操作

- 先在“窗口画布”勾选窗口并开始管理，再按 **Ctrl+Alt+Space** 或点击“进入导航”。下拉框可改为 Ctrl+Alt+N / Ctrl+Alt+M；选择目前只保存在进程内。
- “导航设置”可分别启用纵向滚轮、横向滚轮和双键拖动，并把每格滚轮距离设为 30–600 画布像素（默认 120）。关闭的手势正常传给应用；打开设置或更改配置会退出当前导航。设置目前不跨重启保存。
- 导航中：滚轮纵移、Shift＋滚轮横移，也接收水平滚轮；按住左右双键拖动时，像拖动桌布一样移动视角。系统指针继续移动，窗口仍保持原生大小。
- 导航中 Home 返回原点，Backspace 返回上一视角，Esc 或当前切换键退出。模式键只在导航期间注册；注册失败不进入模式。退出后恢复普通应用的鼠标和键盘交互。
- 默认启用双键拖动时，左右单击在导航中也会被吞掉，以免手势第一键触发应用操作或右键菜单。因此要先按 Esc 再点击按钮或编辑应用；关闭双键拖动后，左右按钮正常传给应用。
- 一次双键拖动记一条历史；250ms 内连续滚轮属于同一段。局部地图滚轮也使用同一规则。一次“上一视角”返回整段起点，空手势不占历史。

输入状态显示于主界面，并有不激活、无任务栏项的导航浮层。快捷键冲突显示实际失败，提供其他组合；不会显示已进入而实际未注册。启用时若鼠标键尚未松开，先提示释放，再允许进入。

## 线程和状态

`GlobalNavigationInput` 在独立 STA 消息线程安装 WH_MOUSE_LL 并注册线程快捷键，回调只判断输入、配对按钮并加入有界队列。它不读取窗口目录、不移动窗口、不写文件，也不把 UI/COM 工作放进钩子回调。UI 通知只启动 16ms 帧计时器；每帧取队列并合并位移，随后调用 T06 管理会话。导航退出且本地滚轮手势结束即停帧计时器；空闲不扫描桌面。

`NavigationInputGate` 保留被吞掉的按下标记，退出后仍吞掉对应松开，直到配对结束。鼠标移动本身继续传递给系统，以免钉住系统指针的位置；应用不接收导航的按钮按下、松开或滚轮。`NavigationGestureSession` 只在 UI 帧刷新提交相机目标，并在手势结束时记录一次起点。新导航还会撤销旧的待激活请求，避免平移后迟到的聚焦请求抢焦点。

输入队列上限 256；积压或回调异常会退出捕获并通知主线程暂停恢复。UI 心跳超过 1800ms 未更新时，输入线程独立退出模式并释放模式键，待 UI 恢复再暂停画布。退出、显示配置变化、管理失败均结束导航；正常关闭释放快捷键、钩子、线程和浮层。钩子被系统超时移除的行为由 Windows 决定，不能靠成功安装承诺永远有效。

## 验证记录

- 最终 Release 构建 0 警告、0 错误；119/119 模型、6/6 日志文件、40/40 原生检查通过，六页、浮层与设置对话框渲染通过。
- 21 项导航模型检查覆盖正常透传、持键拒绝进入、按钮配对、退出后释放、两种双键顺序、系统指针透传、滚轮突发边界、Shift/水平轴、拖动历史、空手势、轮/拖切换、帧合并、Esc、故障取消和拒绝移动。额外管理检查验证新平移取消旧待激活。
- 其中 4 项配置检查验证禁用轴/双键时透传、局部地图遵守禁用项、整格/半格距离缩放以及越界配置拒绝。已查看设置对话框的选项、240 像素示例和保存/取消；配置保存后的原生手势组合整体验证继续留在试用验收范围。
- 2 项新增原生检查验证独立输入线程初始不捕获/不激活、快捷键冲突可见、释放后可重新注册。它们不进入导航，不拦截用户输入。受限进程实测 RegisterHotKey 被拒绝（错误 5）；正常桌面权限下通过。默认 CI 只跑模型与日志文件检查。
- 真实 GUI 只选择本项目的不透明跨进程 Probe Source：快捷键进入、地图外纵向滚轮使相机到 (0,360)、Esc 退出、一次上一视角回到 (0,0)。切到另一进程 Controller 后水平滚轮使相机到 (240,0)、Source 到 (-126,114)，Esc 后相同区域的纵向滚轮不再改变画布。
- 下拉更改 Ctrl+Alt+N 后成功切换导航；模式中点击暂停按钮被吞掉，Esc 后可正常暂停。更新帧调度后复验全局滚轮、Home/Backspace 的 (0,360)→(0,0)→(0,360)，以及局部地图滚轮 (0,360)→(0,720) 后一次返回 (0,360)。最后恢复 Source 到原始 (228,228)、440×310，日志为空，实验关闭。
- T07 阶段的物理组合当时未验收；2026-10-19 用户已在 `6d756ed` 试用包确认 Shift＋滚轮横移、双键连续拖动、松开后一次 Backspace 返回整次起点，以及 Esc 后任务栏找回/输入。UI 长时间阻塞的看门狗整体验证仍未完成。辅助工具未暴露导航浮层供选择，不能据此宣称浮层的完整视觉验收。

系统计算器、独立测试记事本与任务栏路径的后续证据见[试用记录](trial-validation.md)；更广应用、多屏及混合 DPI 仍需兼容验证。当前可选择导航切换组合，Home/Backspace 和总览组合仍固定，全导航键自由重绑定留在首版后续。
