# 验收与验证

## 当前自动检查

默认检查也运行实际 Windows PowerShell 启动器的独立日志/错误路径，以及发布校验器的有效目录/ZIP与损坏、缺文件、用户数据、调试符号、许可缺失、元数据、跨工具版本、ZIP 重复/越界反例。它们不计入 C# 编号检查数量，也不捕获输入或接管桌面；见[部署记录](deployment.md)。

执行 `scripts/check.ps1` 会先构建整个解决方案，再运行 285 项模型/策略、7 项恢复文件、8 项标签文件和 8 项设置文件检查。文件检查也进入默认 Windows CI，不要求交互桌面。任一失败返回非零退出码。`dotnet test` 不代替本项目的 Checks 程序。

| 检查 | 对应需求 | 验证内容 |
| --- | --- | --- |
| Pan preserves layout | FR-01/02 | 多次跨正负坐标平移后，世界布局与相对位移不变 |
| Focus preserves layout | FR-03 | 远处窗口中心映射到视口中心，窗口世界位置不变 |
| Home and back | FR-04 | 返回原点/上一视角不收拢窗口 |
| Overview is spatial | FR-05 | 统一比例、空间顺序、距离和负坐标逆变换正确 |
| Dynamic bookmarks | FR-06 | 超过九个书签；删除书签不会让其他 ID 指错位置 |
| Invalid geometry | NFR-04 | 非数、非正尺寸、不可用地图范围在投影前被拒绝 |
| Missing targets | FR-03/06 | 已关闭或不存在的目标不会改变相机和历史 |

`scripts/check.ps1 -SmokeUi` 以透明、无任务栏项且不激活的方式初始化桌面壳，绘制管理、模型、窗口、显示器、地图、恢复和标签七页，以及导航浮层/设置、总览、预览降级和标签命令状态后关闭。JSON 保存计数和监听状态，不写标题；窗口页和地图图片可能包含标题，仅本地保留。它不证明真实接管、全局手势或 DPI 兼容已经验收。

`-NativeChecks` 额外运行 65 项原生检查，覆盖发现、显示器、事件、系统通知、恢复、离屏、真实管理/新窗接入、区域整理/撤销、输入注册/释放及初始保存组合、总览/预览和焦点身份保护。仅改变项目自身测试窗口；输入检查不进入导航，不捕获用户输入。全局快捷键注册需正常桌面权限，受限进程可能明确失败。完整范围另见[管理说明](managed-canvas.md)、[导航说明](global-navigation.md)、[空间总览](spatial-overview.md)和[新窗接入](runtime-window-admission.md)。

本地设置的 UI 检查使用实际复选框/菜单和导航设置应用函数保存，再重建管理器读取，并核验保持未接管、无恢复记录；损坏文件下保留运行选择且不覆盖原字节。完整字段、并发与失败边界见[本地设置](local-preferences.md)。

托盘状态和入口的模型、实际共享菜单与导航设置模态保存/取消、总览准备期间延后动作，以及实际独立恢复进程的忙状态和结果核验见[托盘记录](tray-control.md)。重复暂停保留待恢复证据；只有有效完整报告和重新核验空日志才确认恢复，画布仍不自动开始。自然鼠标及 Explorer 重启路径继续纳入兼容矩阵。

`-NativeOverviewChecks` 另在交互桌面的实际 WinForms 消息循环检查原生 presenter，包括三尺寸、原生/纯色、反向/空闲、地图与工作区预览、模态、合成 DPI 及资源释放；它不在默认无交互 CI 中运行。启动策略另有纯模型检查，覆盖 Windows build 边界、冲突参数下的旧版回退与纯色入口。

## 性能验证计划

M2 起记录 OS build、CPU/GPU、分辨率、刷新率、DPI、窗口数量及测量工具。单屏 1920×1080 / 60 Hz / 10 个普通窗口作为第一组基线；目标输入到可见运动的 P95 不超过 50ms，平移调度按刷新率合并。该数值是开发目标，尚无实测结果，不代表对任意应用的性能保证。

30 个及更多窗口、动态内容窗口、预览开关、离屏窗口增长都单独测量。空闲时采用事件驱动，不持续全量轮询或绘制；CPU/GPU/内存占用先建实测基线，再制定限制。

总览已建立 1/10/30/60 自有原生源、预览开关与约半数离屏的 48 样本夹具，记录真实 DWM 注册/更新/释放、进程 CPU/私有内存/句柄和合成回调。复现命令、COM 查询作用域优化及测量边界见[负载基线](overview-load-baseline.md)。这部分没有实际键鼠输入或桌面图像，不代表上述输入 P95、GPU 或第三方应用矩阵已经验收。
