# 首个正式版本验收清单

目标是可交付的 v1.0.0；当前仍为私有内部试用。以[需求基线](../windows-spatial-canvas-requirements.zh-CN.md)和[验收场景](acceptance.md)判断完成，打包成功或单次回归通过不替代未完成条件。本文记录截至 2026-10-25 的证据与缺口，T11、T12、T13 保持开放。

## 功能与质量

| 需求 | 已有证据 | 正式版前剩余工作 |
| --- | --- | --- |
| FR-01 连续平移 | 自有原生多窗、用户 3440×1440 / 100% 和同 DPI 双屏平移 | 更广设备与应用组合 |
| FR-02 世界布局与新窗 | 外部拖动回写、全量接入、空位放置、固定/重新纳入、五窗故障恢复 | 普通应用长期创建/关闭，物理便签快捷键/菜单与软件快捷方式 |
| FR-03 聚焦与找回 | 总览选窗、离屏激活、用户任务栏找回后输入 | 管理员应用及关联窗口矩阵 |
| FR-04 原点与历史 | 用户滚轮/双键拖动后整段返回；模型往返 | 输入异常、频繁中断与长期历史 |
| FR-05 空间总览 | 地图/搜索/选择/取消/真实预览；用户远控确认新版无明显卡顿；资源管理器 Tab 修复通过 | 本地实际呈现、物理快速输入矩阵、原生工作区编辑 |
| FR-06 位置工作区 | 256 条稳定身份、重启、损坏保留、用户真实视窗/空区域/边缘裁剪 | 原生宿主的完整编辑自然操作 |
| FR-07 固定背景和任务栏 | 原生矩形检查、用户任务栏找回及悬停预览 | 更广任务栏/桌面组合；不承诺离屏预览持续更新 |
| FR-08 输入及配置 | 用户自动导航/右击/双键、设置持久化、边缘/准星；六项改键、保留键规则和冲突回滚；本机触控板在 b02cd13 上通过双轴、单次右键与菜单后连续滚动复验 | 其他设备/实体触屏、六项物理改键、UI 阻塞与误触压力；Tab/Esc 固定保留 |
| FR-09 生命周期 | 增量事件、身份复用保护、外部编辑、逐窗关闭/隐藏/最小化与恢复；原生快照竞态及空画布事件接入回归；正常启动自动开启 | 自然启动创建/最小化/关闭循环、总览恢复最小化条目、最大化/全屏完整逐窗语义，见下文 |
| FR-10 恢复 | 正常退出、GUI 强杀、跨进程卡顿、独立工具、损坏日志保留；原位置完全离屏的确定性回退 | 真实系统切换、屏幕拓扑改变后的硬件验收 |
| FR-11 整理撤销 | 选择/预览/取消/确认/撤销及拒绝移动回归 | 自然操作与更多设备 |
| FR-12 多屏/DPI | 用户同 DPI 双屏；系统消息排队和暂停后保留画布 | 混合 DPI 支持、真实拔插/更换主屏/睡眠 |
| NFR-01 位置正确 | 模型不变式、原生相对位置与用户验证 | 扩展组合与长期运行 |
| NFR-02 可恢复 | 先登记后移动、句柄身份/标记、独立恢复 | 硬件切换与更多异常路径 |
| NFR-03 响应性 | 高频合并、非阻塞移动、48 个自有总览负载样本 | 真实输入到可见运动 P95、GPU/呈现帧、长期资源 |
| NFR-04 数值正确 | 非有限坐标、溢出、拓扑和投影边界检查 | 硬件变化交叉回归 |
| NFR-05 本地数据 | 本地设置/书签/恢复、图像内存生命周期、发布排除运行数据；仓库内容与正文审计未检出本机数据；main 历史匿名化及指定旧 Actions 清理完成 | 平台只读 PR/旧提交副本仍待 #72 处理；正式产物与记录继续隐私审查 |
| NFR-06 失败降级 | 预览/激活拒绝、关闭目标、恢复失败保留 | 单窗异常不影响其他窗口的最终产品语义 |
| NFR-07 可配置 | 备用组合及冲突失败反馈 | 完整重绑定与保留系统输入规则 |

需求规定用户最小化时保留世界位置并只暂停该窗口，从地图选择时尝试恢复；最大化/全屏同样是临时状态。关闭现已逐窗清理，隐藏/最小化局部挂起并保留世界位置，任务栏恢复后可找回；总览恢复最小化条目以及最大化/全屏仍未满足完整逐窗要求，不能用“特殊窗口不支持”替代需求。后续保留身份、恢复日志和关联模态保护。最新触控异步消息泵及快照竞态见[touch-message-pump-and-minimized-windows.md](touch-message-pump-and-minimized-windows.md)。

- [ ] 完成[仓库隐私审计](repository-privacy-audit.md)的平台副本处理；main 历史和指定 Actions 记录已清理，但只读 PR/旧提交仍可访问，#72 保持开放。
- [ ] 完成上述功能缺口、真实输入与设备/应用矩阵，并记录失败与限制。
- [ ] 干净 Windows、未安装 .NET 的完整便携包试运行、升级/回退及恢复演练。
- [ ] 完整第三方分发审查与项目正式发布许可；仓库保持私有。
- [ ] 固定正式版版本号、对应提交/CI/包校验、发布说明与可追溯交付记录。

当前已通过的远控观感不等于本地 GPU/帧时间证据；合成系统消息不等于真实睡眠或拔插。所有桌面图像、原始报告、运行设置和恢复记录继续只在本地保留，GitHub 只记录源码、文档及匿名计数。
