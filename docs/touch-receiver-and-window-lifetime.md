# 触控滚动接收与持续画布

2026-10-24。用户确认触控提示条一直显示、指针位于桌面，但从鼠标导航切换后两指滚动无效；另反馈关闭新增窗口会退出整个画布。本次同时调整接收路径、窗口生命周期和正常启动行为。

## 触控输入

先前仅滚动模式移除了接触层，只依赖低级鼠标钩子。驱动直接投递到目标窗口的 `WM_MOUSEWHEEL` / `WM_MOUSEHWHEEL` 没有稳定入口。本次在输入线程为每个显示器工作区创建一个不激活的原生接收窗口，使用 1/255 的分层透明度；不覆盖任务栏，也不截取屏幕或捕获光标。窗口过程和钩子复用精度、双轴、Shift 与 Ctrl 累计逻辑。钩子已消费的事件不会再由目标窗口累计。

低级按钮事件继续交给系统，并在放行前为接收器设置 `WS_EX_TRANSPARENT`。完整左右、中键和侧键按住期间保持透明；松开后等待至少 100ms，再由原有输入计时器重新接收滚动。重新接收和前台变化时只把接收器放到普通窗口前，不激活或更改应用之间的层级。若按钮意外直接到达接收器，立即解除并退出该模式；不向未知目标重放点击。退出、暂停、总览、设备切换或输入线程关闭都会销毁接收器。

微软文档说明目标窗口通过窗口过程接收[滚轮消息](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-mousewheel)，分层窗口使用 `WS_EX_TRANSPARENT` 时鼠标事件会传给下方窗口，见[分层窗口命中测试](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)。本次隐藏夹具验证真实窗口消息与透明样式，没有用实际系统点击代替设备验收；物理命中和具体驱动仍需自然操作复验。

触控条和鼠标导航提示共用圆角深色半透明外观与荧光蓝绿像素文字。触控条只显示“双指平移”、总览和退出。鼠标切到触控前清除旧手势的按住/拖动状态，避免 UI 消费层仍认为旧双键拖动未结束。“输入状态”增加匿名钩子/接收窗口消息计数，便于区分两条路径。

## 关闭与短暂隐藏

窗口确实关闭、身份已替换且原生恢复标记不再匹配时，仅提交移除该窗的恢复记录和模型条目，不移动或恢复其余窗口。若目录暂时漏报而原生身份/标记仍匹配，不能当作关闭，继续安全暂停核验。关闭动画目标会取消该目标的激活请求；系统把前台交给剩余离屏窗口时，不把这次回落误认为用户主动找回。

常见关闭过程先发送隐藏、再发送销毁。隐藏且身份仍匹配时只暂停该窗的移动，清空它的待确认请求，保留世界坐标；重新显示为可用普通窗口时回到保存的世界位置。最后一个窗口关闭后画布仍运行、保留相机和工作区，后续新窗继续接入。最大化、最小化、置顶、关联模态及身份不可验证的完整逐窗语义仍是 T11 的后续工作。

## 启动

正常启动在设置读取、设备、事件监听和输入初始化就绪后自动开始，纳入所有符合现有准入规则的普通窗口；新窗默认自动接入，用户保存的关闭自动接入选项仍生效。便签独立，权限不足的目标跳过。没有可用窗口时也保持空画布运行。

旧恢复记录、损坏设置、设备不可用或输入初始化失败不绕过原有保护。手动暂停、独立恢复完成和系统切换后继续等待用户开始。透明测试入口不自动接管。为避免操作工作桌面，本轮没有运行正常启动入口接管用户现有窗口；空启动和后续接入使用自有模型/原生窗口验证。

## 回归

- 329 项模型：空画布、新增后任意顺序关闭、最后一窗关闭再接入、隐藏后重入、前台回落、关闭过渡目标、拒绝漏报丢失所有权；旧双键状态到触控两轴滚动也覆盖。
- 24 项文件检查、19 组隔离输入 worker 检查；隐藏原生接收器经真实 worker 消费目标消息，透明周期不截获完整按钮序列，暂停不残留窗口。
- 99 项原生检查，以及透明 UI 和完整原生总览检查；原生生命周期夹具只使用自己的窗口，验证关闭后存活窗口位置、相机、前台和恢复记录。
- 合成工具条渲染检查窄/宽布局与按钮文字；真实触控板两轴滚动、应用点击/拖动及自然启动关闭循环等待新包复验。源码和远端记录不包含本地输入轨迹、真实窗口身份、画面或恢复文件。
