# 空间总览（T08）

2026-10-19 反馈改进：当前操作以[自动导航、多屏与工作区说明](interaction-refresh.md)为准。本文保留早期阶段的实现和验证证据；其中单屏限制、手动模式、独立标签页及默认关闭自动接入的描述属于旧版。

2026-10-18。总览显示当前管理会话的窗口，共用一个比例与坐标变换；搜索和方向选择只改变选中项，确认后才改变工作相机。T09 已接入可关闭的 DWM 画面及离屏/失败标题降级，详见[预览说明](overview-previews.md)。下面保留 T08 的阶段验证记录。

## 操作

1. 开始画布管理后按 **Ctrl+Alt+O**，或点击“空间总览”。若正在导航，会先结束手势；待本次原生位置确认完成再打开总览。快捷键冲突显示原因，界面按钮仍可使用。
2. 输入标题搜索；不匹配的卡片变暗，位置、尺寸与投影基准保持。方向键按空间邻近选择；Tab / Shift+Tab 可轮选重叠窗口，Ctrl+F 聚焦并全选搜索，F5 显式适配全部。
3. Enter 或单击卡片确认，先整体移动相机、确认原生位置，再请求激活。无匹配或管理已暂停时不能确认。
4. Esc、再次 Ctrl+Alt+O 或取消按钮退出。工作相机与历史保持；在窗口身份和临时标记仍匹配、且用户未切到其他应用时，尝试返回打开总览前的窗口。状态只有在实际核对前台 HWND 成功后才显示“已返回原窗口”。

总览在主窗口内临时占据工作区，使用原任务栏项，关闭后恢复主窗口的边框、大小、显示状态、标题及置顶状态。它不修改桌面/任务栏位置，不向卡片内转发编辑输入。原模态承载在实际测试中受到自动化边界限制，最终采用主窗口切换，搜索输入和取消返回已经真实验证。

## 状态与生命周期

`SpatialOverviewSession` 拷贝开始相机及窗口快照，独立保存查询、选择与投影。搜索不重排，标题/边界更新和关闭同步不自动适配；仅显式 F5 或实际地图尺寸变化重算投影。方向选择按目标半平面、距离与偏离角度评分；大距离使用对数形式，避免平方溢出。极小卡片仍可通过搜索和键盘选择。

打开期间暂停管理会话的工作导航和停放目标的自动前台跟随；全局导航也不进入模式。确认前重新读取目录及身份，再解除暂停并提交聚焦。取消不提交相机，也不增加历史。已关闭且原生所有权失效的目标从总览和画布移除，其余窗口继续；身份无法核验等异常仍安全暂停，恢复失败保留日志。当前规则见[生命周期修正](touch-receiver-and-window-lifetime.md)。

取消的焦点书签不保存标题或位置：保存 HWND/PID/启动时间，并设置独立 GUID 名称和随机整数的临时窗口属性。返回前核验当前身份、属性、可见性和当前虚拟桌面；窗口关闭或复用不恢复焦点。用户已切到其他应用时不覆盖其前台。书签正常释放时清理自己的属性；它与恢复会话的 marker 分离，不授权移动。该机制受 UIPI 和 Windows 前台激活策略限制，失败时保留原视角并由用户点击目标。

主窗口承载会在正常关闭或展示失败时恢复界面状态；显示配置变化、显式暂停和退出会结束总览。卡片的辅助功能对象按 Guid 缓存，标题与边界动态读取，目标关闭后不可继续确认。

## 验证记录

- 最终 Release 构建 0 警告/错误；136/136 模型、6/6 文件、42/42 原生检查通过。
- 15 项总览模型检查：统一比例、搜索不重排、四向邻近、无反向绕回、空结果、取消/确认、关闭移除、标题/边界同步、重叠轮选、命中、显式适配、空会话、非法身份与远距离。另有导航冻结和成组关闭清理检查。
- 2 项新增原生检查：焦点 marker 对隐藏/关闭和释放的校验，以及同一窗口多个独立 marker 不相互移除、检查不改变前台。
- 渲染查看总览、搜索及主窗口承载 PNG；承载检查实际打开/关闭嵌入视图，并断言主窗口 Bounds、BorderStyle、标题、TopMost 完整恢复。
- 本机单屏 2560×1440、150% DPI。实际只接管自己的 Source 与 Controller 两窗：从相机 (240,0) 搜索 Source 后匹配 1/2，卡片及视口保持；Esc 后仍为 (240,0)。方向左键由 Controller 选择 Source，Enter 后相机为 (-870,-339)，Source 居中并可原生文字输入。
- 从 Source 再打开总览，输入无匹配文本后 Enter 不退出、不跳转；Esc 后视角保持，Source 返回前台。一次上一视角回到 (240,0)，证明取消未添加历史。最终构建另从 Source 打开后 Esc，界面显示经过原生前台核验的“已返回原窗口”。
- 最终构建在总览仍打开时结束自有 Probe 进程：两张卡片从 2/2 变为 0/0，确认禁用，Enter 无动作；Esc 返回窗口数 0 的暂停主界面，恢复日志为空。所有试验程序已退出。
- 新建透明测试窗口的桌面登记存在时序：焦点检查等待消息分派后再查询；旧恢复 fixture 首轮查询也先分派消息，保留原 3 秒限时，并使失败提示区分准入等待与恢复子进程。未放宽生产恢复期限。

T08 阶段使用标题视图；后续 T09 的预览资源、离屏占位与实测记录见[预览说明](overview-previews.md)。普通第三方应用、任务栏实际点击、物理 Shift/双键组合、多屏和完整主 GUI 强杀流程仍按[原型交付检查](prototype-plan.md)推进，不能把本阶段两窗测试当作整个原型验收。
