# 系统切换与画布保留

锁屏、会话断开、电源状态或显示配置变化时，先结束导航、停用画布输入并取消总览，再在当前原生事务、编辑窗口和独立恢复结束后暂停恢复。解锁、重连、恢复运行、分辨率或 DPI 变化还会重新读取设备与窗口。完成后保持暂停，由用户检查设备并点击开始；不自动接管、不自动打开面板，也不通过取消总览抢回焦点。

## 消息与调度

主窗口按当前会话注册 [WTS 通知](https://learn.microsoft.com/en-us/windows/win32/api/wtsapi32/nf-wtsapi32-wtsregistersessionnotification)，句柄销毁前注销，重建后重新注册。注册失败显示提示并在重新打开面板或恢复检查时重试。只映射 [WM_WTSSESSION_CHANGE](https://learn.microsoft.com/en-us/windows/win32/termserv/wm-wtssession-change) 中的锁定、解锁、连接与断开事件，不记录会话 ID。

`WM_DISPLAYCHANGE`、`WM_DPICHANGED` 与 [WM_POWERBROADCAST](https://learn.microsoft.com/en-us/windows/win32/power/wm-powerbroadcast-messages) 进入同一 UI 线程队列。重复原因合并，正在执行的批次只能由自身完成；处理期间的新通知留给下一批，不会被旧清理丢弃。电池状态变化等无关消息不触发恢复。

消息到达时立即关闭画布输入可用状态，实际原生恢复通过消息循环延后。窗口被模态框禁用、会话忙、总览正在结束或独立恢复运行时，保留请求，等待安全边界。销毁前先停止调度并使旧回调失效。队列不增加后台线程或空闲全桌面轮询。

Windows 不保证应用有足够时间在睡眠前完成所有跨进程恢复，因此这不是“阻止睡眠”或“睡眠前必定恢复完”的承诺。已写入的恢复记录仍是失败重试的依据；恢复运行时重新检查，未完成项保持待恢复状态。

## 显示配置更新

此前配置变化会销毁并重建管理会话。现在仅在暂停且无原生事务时更换显示投影与停放规划，保留窗口世界位置、相机位置、上一视角和工作区；更新视口尺寸并使旧整理撤销失效。重新开始沿用保留的画布，不把屏幕上恢复后的矩形误当成新的世界布局。

读取失败会禁用开始，不允许继续使用旧设备数据。重新读到有效配置后，即使拓扑与上次相同，也会解除该限制。混合或未知 DPI 仍拒绝开始；保留逻辑画布并不意味着混合 DPI 已受支持。已有恢复失败时，更新投影不会清空日志或宣称恢复完成。

## 验证范围

本轮检查新增以下范围：

- 五项队列检查覆盖通知风暴、批次身份、重入、刷新策略和不可变快照。
- 四项管理检查覆盖新拓扑、负原点、相机/历史/工作区保留、运行中拒绝替换、混合 DPI 拒绝和恢复日志保留。
- 三项原生检查验证实际自有 HWND 的注册/注销、线程与进程所有权及消息映射。
- UI 夹具向自己的 HWND 发送消息，验证即时输入限制、模态所有者延后、重入请求、显示读取失效及销毁后旧回调失效；不改变真实会话或电源状态，不激活用户窗口。

一次原生回归明确发现透明测试窗口处于其他 Windows 虚拟桌面，生产准入按规则拒绝。测试准备现在只允许将本测试进程的窗口移到已验证的自有锚点所在桌面，核验前台不变；不切换或创建桌面，不移动用户窗口，不放宽生产准入。其他偶发文件替换或夹具时序问题继续跟踪。

真实锁屏、睡眠、远控重连、拔插显示器、更换主屏和不同 DPI 的硬件矩阵仍未完成。系统调整原始屏幕外 `WINDOWPLACEMENT` 后的恢复核验也需专项验证，不据此关闭 AT-12 或 T11。
