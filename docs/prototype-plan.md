# 可试用原型的交付检查

持续目标：推进到用户能实际体验连续窗口画布的 Windows 原型。当前 T03 的只读真实地图是中间步骤；完成原型需要以下实际功能和验证证据。

- [ ] 能选择普通应用并开始/暂停画布管理；准入与失败原因清楚可见。
- [ ] 真实窗口在连续二维世界保留位置和尺寸，相机平移不收拢布局；背景与任务栏保持固定。
- [ ] 提供滚轮纵移、Shift 横移、左右双键拖动、退出导航模式与清楚的快捷键说明；一次手势对应一次历史。
- [ ] 能聚焦远处窗口、返回原点和上一视角；从任务栏激活离屏目标可以找回。
- [ ] 空间总览保持窗口正确相对位置、尺寸与视口框，支持选择、搜索、确认跳转和取消；预览资源失败时有可选择的占位卡片。
- [ ] 动态位置标签可增加、重命名、删除、搜索、跳转并在重启后保留，无固定槽位上限。
- [ ] 接管前落盘恢复日志；正常退出可恢复；强制结束后有可独立运行的恢复命令；失效和复用 HWND 不被误恢复。
- [ ] 完成离屏策略实验，记录任务栏预览、动态刷新、弹窗、权限和 DPI 的支持范围。实际测试用户机器配置，并明确未验证的组合。
- [ ] 提供可启动的本地试用产物、运行/恢复说明和已知限制；构建、相关模型/原生检查、真实桌面交互和恢复演练均有记录。

实现顺序：T04 恢复 → T05 离屏策略实验 → T06 真实平移 → T07 导航 → T08/T09 总览 → T10 标签 → 原型打包与试用验收。T11–T13 中涉及安全恢复、实际运行和兼容边界的条目随这些阶段完成；正式发布仍要求完整兼容与性能矩阵。

阶段提交、PR、绿灯测试或示例地图不能代替上述实际体验。只有检查项得到当前源码、运行产物和对应范围的实际验证支持，才把持续目标标为完成。
