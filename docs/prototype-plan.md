# 可试用原型的交付检查

持续目标：推进到用户能实际体验连续窗口画布的 Windows 原型。当前已有单屏真实接管、全局导航、空间总览、预览降级及持久化位置标签；组合手势、普通应用兼容和运行中新窗口接入继续推进。下面包含多个条件的条目只有全部验证才勾选。

- [ ] 能选择普通应用并开始/暂停画布管理；准入与失败原因清楚可见。
- [ ] 会话中新开的普通窗口可纳入当前画布，并优先放在当前视口附近的空闲位置；不挤压既有世界布局。对应原需求 FR-02，不能仅靠重建整幅画布接入。
- [ ] 真实窗口在连续二维世界保留位置和尺寸，相机平移不收拢布局；背景与任务栏保持固定。
- [ ] 提供滚轮纵移、Shift 横移、左右双键拖动、退出导航模式与清楚的快捷键说明；一次手势对应一次历史。
- [ ] 能聚焦远处窗口、返回原点和上一视角；从任务栏激活离屏目标可以找回。
- [ ] 空间总览保持窗口正确相对位置、尺寸与视口框，支持选择、搜索、确认跳转和取消；预览资源失败时有可选择的占位卡片。
- [x] 动态位置标签可增加、重命名、删除、搜索、跳转并在重启后保留，无固定槽位上限。证据与边界见[标签说明](location-bookmarks.md)。
- [ ] 接管前落盘恢复日志；正常退出可恢复；强制结束后有可独立运行的恢复命令；失效和复用 HWND 不被误恢复。
- [ ] 完成离屏策略实验，记录任务栏预览、动态刷新、弹窗、权限和 DPI 的支持范围。实际测试用户机器配置，并明确未验证的组合。
- [ ] 提供可启动的本地试用产物、运行/恢复说明和已知限制；构建、相关模型/原生检查、真实桌面交互和恢复演练均有记录。

实现顺序：T04 恢复 → T05 离屏策略实验 → T06 真实平移 → T07 导航 → T08/T09 总览 → T10 标签 → 原型打包与试用验收。T11–T13 中涉及安全恢复、实际运行和兼容边界的条目随这些阶段完成；正式发布仍要求完整兼容与性能矩阵。

T04 已实现写前日志、实例标记、独立 EXE 与崩溃恢复演练，详见[恢复说明](recovery.md)。上面的恢复项仍待 T06 真正接管后集成复验，不能以基础组件测试替代整个画布原型验收。

T05 已比较有界停放与空区域裁剪，加入规划器、受登记保护的原生移动入口、基础 DWM 资源与 Probe 程序；视觉确认离屏旧帧、裁剪空白和返回后输入恢复。任务栏 hover 与多屏硬件边界明确记录在 [ADR 0002](adr/0002-bounded-offscreen-parking.md)，不能以 API 成功代替实际图像更新。

T06 已接入真实管理会话：勾选接管、连续平移、地图聚焦与原生输入、原点/上一视角、暂停恢复及同选择继续布局已实测；跨进程卡顿、部分拒绝与迟到移动有检查。前台激活离屏目标已通过真实 OS 激活验证，任务栏实际点击路径仍待验收。当前检查为 97 模型、6 文件、38 原生；完整记录见[管理说明](managed-canvas.md)。T07、T08/T09、T10 和试用打包仍未交付。

阶段提交、PR、绿灯测试或示例地图不能代替上述实际体验。只有检查项得到当前源码、运行产物和对应范围的实际验证支持，才把持续目标标为完成。

T07 已实现独立线程输入、显式模式、可换切换键、Esc/Home/Backspace、滚轮/双键状态机与按帧/手势合并；全局与局部滚轮、跨进程水平滚轮、退出后透传和导航键已真实验证。119 模型、6 文件、40 原生检查通过；实际 Shift/双键组合、看门狗 UI 阻塞整体验证继续待验收，详见[全局导航](global-navigation.md)。未把模型覆盖算作完整组合体验。下一步 T08 总览选择与取消，接续 T09 预览降级和 T10 标签。

T08 已有稳定投影、标题搜索、方向/重叠选择、确认后聚焦、取消不改相机/历史、原窗口焦点校验返回和关闭移除；两个不透明跨进程自有窗口已实测。136 模型、6 文件、42 原生检查与承载状态恢复渲染通过，详见[空间总览](spatial-overview.md)。当前卡片仅标题视图，T09 资源失败/离屏旧帧的实际总览集成和 T10 标签仍未完成，因此完整总览交付项暂不勾选。

对照 FR-02 补出此前检查表遗漏的会话中新窗口接入与空闲位置放置。当前接管选择固定，创建事件虽会更新候选目录，但还不能无重建地加入运行中会话；须在试用打包前补齐，不以只读创建监听代替此项。

T09 已在真实总览中接入有界 DWM 资源、独立身份标记、比例适配、失败重试和标题降级，153 模型、6 文件、45 原生检查通过。已实测画面帧数变化、预览开关、搜索、离屏占位仍可定位与来源关闭。发现并修复隐藏先于销毁时的暂停地图残影，以及总览关闭后导航提示未更新。详见[预览说明](overview-previews.md)。完整总览项待普通应用与其余试用集成后复核，T10 及 FR-02 接续。

T10 已实现标签 UI、稳定 ID、重名位置区分、真实会话跳转、JSON 版本/原子存储及损坏只读/备份重建。168 模型、14 文件、46 原生检查通过；256 条标签有身份/存储验证，可见主程序验证新增/重命名/搜索、(0,1200)→(0,0) 跳转、正常恢复和关闭后重启保留，两窗原生及组件命令验证删除不动窗口。损坏文件的主 GUI 只读与重新读取路径已实测。独立标签交付项据此勾选；其余原型条件仍须继续证明，见[标签记录](location-bookmarks.md)。
