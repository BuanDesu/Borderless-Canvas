# 可试用原型的交付检查

持续目标：推进到用户能实际体验连续窗口画布的 Windows 原型。已有单屏接管、全局导航、总览/预览、持久化标签及新窗接入；试用包已在计算器、独立测试记事本和 Probe 四窗会话验证。物理组合手势和任务栏实际路径仍待验收，目标保持进行中。下面包含多个条件的条目只有全部验证才勾选。

- [x] 能选择普通应用并开始/暂停画布管理；准入与失败原因清楚可见。系统计算器、独立记事本与四窗会话实测见[试用验证](trial-validation.md)，其他应用仍按兼容矩阵逐项验证。
- [x] 会话中新开的普通窗口可纳入当前画布，并优先放在当前视口附近的空闲位置；不挤压既有世界布局。对应 FR-02，模型、原生及真实自有窗口实测见[接入说明](runtime-window-admission.md)。普通第三方应用兼容另行验收。
- [x] 真实窗口在连续二维世界保留位置和尺寸，相机平移不收拢布局；背景与任务栏保持固定。单屏原生批次/背景和任务栏矩形检查及四窗跨正负坐标实测见[管理说明](managed-canvas.md)与[试用验证](trial-validation.md)。
- [ ] 提供滚轮纵移、Shift 横移、左右双键拖动、退出导航模式与清楚的快捷键说明；一次手势对应一次历史。
- [ ] 能聚焦远处窗口、返回原点和上一视角；从任务栏激活离屏目标可以找回。
- [x] 空间总览保持窗口正确相对位置、尺寸与视口框，支持选择、搜索、确认跳转和取消；预览资源失败时有可选择的占位卡片。模型、原生、自有窗口及系统普通应用证据见[总览](spatial-overview.md)、[预览](overview-previews.md)与[试用验证](trial-validation.md)。
- [x] 动态位置标签可增加、重命名、删除、搜索、跳转并在重启后保留，无固定槽位上限。证据与边界见[标签说明](location-bookmarks.md)。
- [x] 接管前落盘恢复日志；正常退出可恢复；强制结束后有可独立运行的恢复命令；失效和复用 HWND 不被误恢复。组件/原生身份检查、真实主程序正常退出及五窗故障演练见[恢复说明](recovery.md)和[接入记录](runtime-window-admission.md)。
- [ ] 完成离屏策略实验，记录任务栏预览、动态刷新、弹窗、权限和 DPI 的支持范围。实际测试用户机器配置，并明确未验证的组合。
- [x] 提供可启动的本地试用产物、运行/恢复说明和已知限制；构建、相关模型/原生检查、真实桌面交互和恢复演练均有记录。包内直接启动及 GUI 相邻独立恢复实测见[试用验证](trial-validation.md)，操作见[试用指南](trial-guide.zh-CN.md)。这不替代上方尚未勾选的手势/任务栏验收。

实现顺序：T04 恢复 → T05 离屏策略实验 → T06 真实平移 → T07 导航 → T08/T09 总览 → T10 标签 → FR-02 运行中接入 → 原型打包与试用验收。T11–T13 中涉及安全恢复、实际运行和兼容边界的条目随这些阶段完成；正式发布仍要求完整兼容与性能矩阵。

以下为逐阶段证据，计数和未实现状态对应当时版本；当前以本页检查表及最后一条记录为准。T04 已实现写前日志、实例标记、独立 EXE 与基础崩溃恢复演练，详见[恢复说明](recovery.md)。FR-02 阶段再完成真实五窗管理器故障集成复验。

T05 已比较有界停放与空区域裁剪，加入规划器、受登记保护的原生移动入口、基础 DWM 资源与 Probe 程序；视觉确认离屏旧帧、裁剪空白和返回后输入恢复。任务栏 hover 与多屏硬件边界明确记录在 [ADR 0002](adr/0002-bounded-offscreen-parking.md)，不能以 API 成功代替实际图像更新。

T06 已接入真实管理会话：勾选接管、连续平移、地图聚焦与原生输入、原点/上一视角、暂停恢复及同选择继续布局已实测；跨进程卡顿、部分拒绝与迟到移动有检查。前台激活离屏目标已通过真实 OS 激活验证，任务栏实际点击路径仍待验收。当前检查为 97 模型、6 文件、38 原生；完整记录见[管理说明](managed-canvas.md)。T07、T08/T09、T10 和试用打包仍未交付。

T07 已实现独立线程输入、显式模式、可换切换键、Esc/Home/Backspace、滚轮/双键状态机与按帧/手势合并；全局与局部滚轮、跨进程水平滚轮、退出后透传和导航键已真实验证。119 模型、6 文件、40 原生检查通过；实际 Shift/双键组合、看门狗 UI 阻塞整体验证继续待验收，详见[全局导航](global-navigation.md)。未把模型覆盖算作完整组合体验。下一步 T08 总览选择与取消，接续 T09 预览降级和 T10 标签。

T08 已有稳定投影、标题搜索、方向/重叠选择、确认后聚焦、取消不改相机/历史、原窗口焦点校验返回和关闭移除；两个不透明跨进程自有窗口已实测。136 模型、6 文件、42 原生检查与承载状态恢复渲染通过，详见[空间总览](spatial-overview.md)。当前卡片仅标题视图，T09 资源失败/离屏旧帧的实际总览集成和 T10 标签仍未完成，因此完整总览交付项暂不勾选。
