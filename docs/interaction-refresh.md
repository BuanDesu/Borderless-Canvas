# 试用反馈改进：自动导航、连续多屏和工作区

2026-10-19。本说明更新首个试用原型的操作约定；早期阶段文档保留当时的验证范围。

后续用户已完成本轮全部人工验收，详见下方补充。视觉与布局继续更新为[糖果播放器与 CRT 工作区](candy-glass-design.md)，原 Y2K 描述仅记录本轮原始交付。最新版本允许桌面单独右击打开 Windows 菜单，搜索已移入总览底部；此新增物理右击路径仍待最终包复验。

## 输入与窗口

开始画布后，鼠标处于 Windows 桌面空白处时自动导航：滚轮纵移、Shift＋滚轮横移、左右双键拖动。进入任意应用窗口后恢复应用输入，包括管理器自身和未接管应用；任务栏、菜单和无法识别的浮层不作为桌面。桌面图标所在的 shell 表面也属于导航区域，需要操作图标时先按 Esc。

双键手势从桌面开始后持续到松键，即使窗口移动到指针下方；从应用开始的普通拖动越过桌面也不会被改为相机拖动。Esc 暂停自动导航，指针进入应用再回桌面后恢复。Home 返回原点，Backspace 返回整段手势起点。Ctrl+Alt+Space 和设置中的其他备用组合仍可显式进入手动导航。

桌面空白处的 Tab 或 Shift+Tab 打开总览。应用中的 Tab、Ctrl+Tab、Alt+Tab 等保留原用途。总览内 Tab / Shift+Tab 轮选窗口，Esc 取消；Ctrl+Alt+O 仍作为备用入口。键盘钩子只处理这些控制键，不记录输入文本。

桌面空白处 Ctrl＋滚轮轮选受管理的原生窗口并整体定位相机；浏览器窗口内的 Ctrl＋滚轮保留应用缩放。这里的轮选单位是独立 Windows 窗口，不是浏览器内部标签。

“自动接入之后新开的窗口”默认开启。开始前已有的未选窗口仍被排除；新建普通窗口稳定后加入当前视角附近空位，不重排旧窗口。最大化、全屏、置顶、所属弹窗和无法核验身份等原有准入限制保持。

## 页面与工作区

正常入口只有“窗口画布、设备诊断、恢复中心”。设备诊断含“窗口候选、显示器与坐标、真实空间地图”三个子页；只读诊断不授权接管。空间模型示例只供开发 smoke 检查，不出现在正常使用界面。

Y2K 视觉采用青色、荧光绿和粉色点缀、金属渐变按钮、深紫 PVC 质感卡片与数字网格。工具栏按可用宽度换行，避免长标签挤压重叠。

空间总览上方约 4/5 为地图和选择工具，下方约 1/5 为可水平滚动的工作区卡片。工作区就是命名的相机位置；数量没有固定槽位限制，切换只移动视角，不隐藏另一组窗口。提供原点卡片、保存当前视角、名称筛选、右键重命名/删除，以及管理/存储入口。继续复用原有稳定 ID 和版本化原子存储。

模糊背景取打开总览时的桌面快照，在内存中降采样、模糊和着色；退出立即释放。它不是实时桌面视频，捕获不可用时退化为数字网格。桌面快照不写文件、不进入日志或安装包。DWM 预览独立更新，仍可能停帧或退化为标题卡片。

## 多屏与托盘

移除了“仅单显示器”硬限制，支持所有显示器 DPI 已知且相同的布局，允许副屏负坐标、错位以及各屏不同的任务栏工作区。世界原点对应所有工作区包围框的左上角，可见性取各屏实际工作区的并集，屏间空隙不当作显示空间。离屏停放避开所有物理显示器。聚焦窗口定位到主屏工作区中心，避免落在接缝或空隙；新窗优先主屏空位，再尝试其他屏幕。

混合 DPI 仍明确拒绝：应用跨不同 DPI 屏幕时可能自动调整尺寸，与当前“不改变尺寸”的保护约束冲突。拔插或 DPI/主屏变化会暂停并恢复，再读取配置。模型通过不等于真实双屏硬件体验验收。

关闭或最小化管理器收入系统托盘，画布继续运行；双击图标或选择“打开窗口画布”返回。托盘还提供总览、暂停并恢复、退出并恢复。真正退出请用“退出并恢复窗口”，不要把关闭管理器窗口等同于退出。

## 验证与待验收

- Release：198 项模型、15 项恢复/标签文件和 48 项原生检查通过，0 警告、0 错误；正常三页结构、诊断子页、总览和设置渲染通过，托盘菜单的隐藏/返回/暂停命令经过 smoke 检查。
- 新增模型覆盖自动分流、应用拖动穿过桌面、手势捕获、Esc 恢复边界、Tab 修饰键、同 DPI 双屏平移/停放/恢复、主屏聚焦、屏间空隙和连续轮选。
- 实际 GUI：只选择自有 Source；开始后新增的 Controller 和 Source 自动加入，共三窗，原有未选 Controller 保持未接管。无需模式快捷键即可点击 Source 编辑框、输入文字；应用内 Tab 未打开总览。已查看真实模糊背景、DWM 预览和工作区入口，修复命名框被置顶总览遮挡的所属关系。嵌入总览中的命名框保存流程仍需最终人工体验确认，自动化工具无法可靠把输入定向到该模态框。
- 独立恢复实际恢复三窗，全部原始 placement 验证通过，待恢复记录为零。
- 用户已确认旧包在 3440×1440、100% 缩放功能正常；此前双屏开始失败源于旧代码主动限制，不是该分辨率失败。
- 待人工：最终包上桌面/应用边界的自然手感、桌面 Tab / Shift+Tab、Ctrl＋滚轮、整段双键历史、真实同 DPI 双屏和托盘图标返回。混合 DPI、广泛第三方应用、输入法、性能及正式发布继续保留在 T11–T13。
