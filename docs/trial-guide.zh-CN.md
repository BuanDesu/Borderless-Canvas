# Borderless Flat Window 本地试用

这是连续二维窗口画布的内部试用原型。当前仅开放 **DPI 已知的单显示器、普通窗口**；本机验证环境为 Windows 11 x64，2560×1440、150% DPI。应用保持原生尺寸，背景和任务栏固定，离屏窗口使用有界停放。

## 启动

解压整个目录，保留 EXE、DLL 和 JSON 文件在一起，双击 `Start.cmd` 或 `BorderlessFlatWindow.App.exe`。需要 **.NET 10 Windows Desktop Runtime x64**；无需 SDK、WSL 或管理员启动。当前包为框架依赖包，不含运行时。`manifest.json` 记录源码版本、是否存在未提交修改及文件 SHA-256。

首次建议运行包内 `BorderlessFlatWindow.Probe.exe`，它生成本项目自己的测试窗口，含可输入文字的 Source。先在这些窗口上体验，再选择自己的普通应用。管理器初始不接管任何窗口。

接管单位是整个应用窗口。浏览器或记事本中同一窗口的多个标签会一起移动；若只想把其中一个标签放到画布别处，先将它分离成独立窗口，再选择对应候选。记事本可能在已有窗口中新开标签，打开新文件不一定产生新窗口。

## 体验路径

1. 在“窗口画布”勾选目标，点击“开始 / 恢复画布”。移动前会登记原始位置；准入不支持的窗口会显示原因。
2. 箭头或地图滚轮改变相机，Shift＋滚轮横移；地图卡片可定位窗口。“返回原点”和“上一视角”保留窗口世界位置。
3. 按 Ctrl+Alt+Space 进入全局导航：滚轮纵移、Shift 横移、按住左右双键拖动。按 Esc 退出后再编辑应用。默认导航中左右单击也会被接收，以免双键第一击触发应用；可在“导航设置”关闭双键拖动。组合冲突时在主界面改用其他组合。
4. Ctrl+Alt+O 打开空间总览，输入标题搜索，方向键按空间选择，Tab 轮选重叠项。Enter/单击确认才定位；Esc 取消。离屏、过小、重叠或预览失败时显示标题卡片，仍可选择。F5 适配全部。
5. “位置标签”保存当前相机，可新增、重命名、删除、搜索并跳转。标签没有固定九个槽位；重名项以坐标和短 ID 区分，重启后保留。
6. 运行中勾选新候选并“将勾选新窗口加入画布”；可选“自动接入之后新开的窗口”，默认关闭。自动模式不接管开启前已有的未选窗口；新窗优先空位，不重排旧布局。
7. “暂停并恢复原位”将窗口恢复到各自接管前位置。同一选择再次开始可继续本次进程的布局；正常关闭也会恢复窗口。

## 恢复与文件

默认数据位于 `%LOCALAPPDATA%\BorderlessFlatWindow`：`recovery.json` 是恢复日志，`bookmarks.json` 是位置标签。不要把运行中的恢复日志当作可删除缓存；未恢复的失败记录需要保留以便重试。

主程序异常结束后，重启会进入恢复页；点击“启动独立恢复程序”。也可关闭管理器后直接双击 `Recover.cmd`，它与 GUI 无关。`Inspect-Recovery.cmd` 只显示待处理数量，不移动窗口。恢复核验 HWND、PID、进程创建时间和独立实例标记，跳过已关闭/不匹配的目标，失败项保留。退出码 0 表示处理完成，2 表示仍待恢复，1 表示错误；损坏文件保留并报错。日志正被运行中的管理器使用时，先暂停或退出该管理器再恢复。

自定义数据位置可从终端运行：

```powershell
.\BorderlessFlatWindow.App.exe --journal C:\path\recovery.json --bookmarks C:\path\bookmarks.json
.\BorderlessFlatWindow.Recovery.exe --inspect --journal C:\path\recovery.json
.\BorderlessFlatWindow.Recovery.exe --journal C:\path\recovery.json
```

## 当前限制与验收状态

- 最大化、全屏、置顶、最小化、所属/工具窗口、其他虚拟桌面或无法验证身份的目标不在当前接管范围；关联弹窗或移动失败会暂停并恢复。
- 离屏 DWM 画面可能停留在旧帧；原生窗口返回视口后可继续操作。总览不承诺持续实时刷新，不向缩略图转发编辑输入。
- 标签跨重启保存；窗口世界布局、导航设置和自动接入开关目前仅本次管理器进程有效。
- 多屏/混合 DPI、拔插、休眠、管理员应用、输入法与广泛第三方应用兼容，以及性能矩阵尚未完成。
- 滚轮/键盘导航、总览/原生输入、标签重启、新窗接入和故障恢复已有实测；本包已验证系统计算器、独立生成文本记事本及 Probe 四窗会话，并实际从 GUI 启动相邻恢复程序找回四窗。物理 Shift＋滚轮、双键持续拖动及任务栏实际点击/hover 仍待补齐。
- 当前为私有项目内部试用，未确定正式发布许可证、签名、安装器、托盘或自动更新。

源码构建：`scripts/package-trial.ps1 -NativeChecks` 在 Release 检查后生成新目录与 ZIP，不覆盖已有产物。正式交付以 manifest 和对应版本的实际验证记录为准，打包成功不等于未验证条件已经通过。
