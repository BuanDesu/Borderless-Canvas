# Borderless Flat Window 使用说明

这款软件把 Windows 窗口放在一张可以移动视角的大桌面上。背景和任务栏保持原位，应用窗口保持原来的大小。

## 启动

1. 下载 Windows x64 便携试用版 ZIP，完整解压到一个新文件夹。
2. 双击 `Start.cmd`。便携版已带运行环境，无需另外安装 .NET，也无需管理员启动。
3. 正常启动后会自动管理已有及后续新开的普通窗口。面板显示“已暂停”时，点击“开始”。显示“待恢复”时，先按提示恢复窗口。

请保留解压出来的 EXE、DLL 和其他文件在一起。多屏使用前，把各显示器的 Windows 缩放比例设为相同。可以先运行包内 `Probe.cmd` 打开一个自带测试窗口练习操作。

## 最常用的操作

下列操作在**鼠标位于桌面空白处**时使用。移回应用窗口后，就可以照常点击、输入和滚动页面。

| 操作 | 效果 |
| --- | --- |
| 滚动滚轮 | 上下移动视角 |
| `Shift + 滚轮` | 左右移动视角 |
| 同时按住鼠标左、右键拖动 | 自由移动视角 |
| `Ctrl + 滚轮` | 快速切换并前往窗口 |
| `Tab` / `Shift + Tab` | 打开空间总览；总览内再次按下可返回 |
| `Home` | 回到开始的位置 |
| `Backspace` | 回到上一段移动开始前的位置 |

单独右击桌面仍是 Windows 右键菜单。要框选桌面图标时，先按 `Esc` 临时停止自动导航。将鼠标推到屏幕外缘并继续向外移动，也可以推动视角；停止移动或离开边缘就停止。

## 总览和工作区

按 `Ctrl + Alt + O` 也能打开或关闭总览。点击地图中的窗口即可前往；在下方输入窗口标题可以查找，方向键选择后按 `Enter` 也可确认。按 `Esc` 取消并返回。

移动到常用位置后，打开总览，在底部点击“+”保存为工作区。点击卡片就能回到这个位置，右击卡片可重命名或删除。工作区保存的是观察位置；设置和工作区会保留，重新打开软件不会自动恢复上次的窗口布局。

浏览器内的标签页需要先拖成独立窗口，才能分别放到画布上。

## 触控板、固定窗口和准星

- **触控板**：`Ctrl + Alt + V` 开启触控导航，用两指上下或左右滑动移动视角。单击、双击、拖动和双指轻点右键仍可正常使用。按 `Esc` 或再次按组合键退出。
- **固定窗口**：点击目标窗口，按 `Ctrl + Alt + P`。窗口保持屏幕位置和原有层级，不随画布移动；再次按下可重新加入。标题栏右键菜单也提供便签操作。
- **准星模式**：`Ctrl + Alt + C` 开启，鼠标移动直接推动视角。按 `Esc` 或再次按组合键退出后，再操作应用。
- **修改操作习惯**：主面板“更多（⋯）→ 导航与键位设置”中可调整手势、速度及快捷键。本文使用默认键位。

软件快捷方式 `.lnk` 的右键菜单可“以画布便签模式打开”。Windows 11 可能需要先点“显示更多选项”；该入口可在主面板“更多 → 软件快捷方式右键入口”中关闭。

## 暂停和退出

在任务栏右下角寻找粉紫色小显示器图标；也可能位于“显示隐藏的图标”中。双击打开主面板，右击打开菜单。

- “暂停并恢复窗口”：恢复接管前的位置；之后可点击“开始”继续。
- “退出”：恢复窗口后结束程序。
- 主面板右上角的关闭按钮：仅收起面板，画布继续运行。

## 窗口找不到或启动异常

| 遇到的情况 | 处理方法 |
| --- | --- |
| 找不到主面板 | 双击托盘图标 |
| 窗口移到看不见的位置 | `Ctrl + Alt + O` 打开总览，或从任务栏点击该应用 |
| 显示“待恢复” | 进入恢复中心，按提示运行独立恢复程序 |
| 管理器无法打开，需要独立恢复 | 先退出管理器，再双击包内 `Recover.cmd`；`Inspect-Recovery.cmd` 仅检查，不移动窗口 |
| 总览显示异常 | 退出后，用 `Start-FormOverview.cmd` 启动兼容总览；`Start-NativeOverview.cmd` 可明确使用原生总览 |
| 滚轮没有移动画布 | 检查托盘是否为运行状态、鼠标是否位于桌面空白处；触控板先开启触控导航 |
| 便携版提示文件缺失或运行失败 | 把 ZIP 完整解压到新目录后重试，保留全部文件 |

恢复失败时请保留待恢复记录；不要通过删除日志绕过恢复提示。程序自己的设置、工作区和恢复记录保存在当前用户的数据目录，不包含在下载包中。细节见[部署与恢复说明](deployment.md)。

## 更新和目前的限制

更新时先在旧版暂停并恢复，再从托盘退出。把新版解压到另一个文件夹后启动，不覆盖正在运行的文件。

- 先把最大化、全屏或置顶窗口恢复为普通窗口；管理员权限应用及特殊窗口仍有兼容限制。
- 混合缩放比例多屏暂不接管；真实拔插、睡眠及更广设备组合仍在验收。
- 离屏窗口在总览中的预览可能停帧；返回窗口后再正常操作。
- 锁屏、显示器或电源状态改变后，画布可能为恢复窗口而暂停；检查后手动点击“开始”。

这是便携试用版，完整兼容与性能验收继续进行。框架依赖小包另需 .NET 10 Windows Desktop Runtime x64；便携包自带运行时。包内 `manifest.json` 记录来源版本、运行时和文件校验值，技术说明见[部署](deployment.md)、[验收范围](release-v1-readiness.md)，第三方许可见包内 `THIRD-PARTY-NOTICES.md`。
