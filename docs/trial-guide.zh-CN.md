# Borderless Flat Window 本地试用

这是连续二维窗口画布的内部试用版。支持 **DPI 已知且相同的单屏或多屏、普通窗口**；混合缩放比例暂不接管。应用保持原生尺寸，背景和任务栏固定。新交互和验证边界见[反馈改进说明](interaction-refresh.md)（源码文档）。

## 启动

解压整个目录，保留 EXE、DLL 和 JSON 文件在一起，双击 `Start.cmd` 或 `BorderlessFlatWindow.App.exe`。框架依赖版需要 **.NET 10 Windows Desktop Runtime x64**，自包含便携版已携带运行时；两者均无需 SDK、WSL 或管理员启动。`manifest.json` 的 `frameworkDependent` 区分模式，`bundledFrameworks` 记录随包补丁，另记录源码版本、是否存在未提交修改及文件 SHA-256。启动失败提示、升级/移除和许可清单见 `deployment.md` 及 `THIRD-PARTY-NOTICES.md`。

正常启动会自动开始画布并接管所有可用普通窗口，后续新窗默认自动接入，便签独立。首次可在单独测试桌面先运行包内 `Probe.cmd`，它生成本项目自己的测试窗口，含可输入文字的 Source；框架依赖包的 Probe EXE 在根目录，便携包在 `tools/probe/`。待恢复记录、设置读取失败或设备/输入初始化未就绪时不会自动开始。手动暂停后需再次点“开始”。

Windows 11 build 22621 及以上正常启动已默认使用[原生总览](native-overview-presenter.md)：保留地图、搜索与工作区，绕过同步桌面位图读回。较早系统保留原路径；`Start-NativeOverview.cmd` 可显式启用原生路径。若遇到兼容问题，先从托盘“退出并恢复窗口”，再用 `Start-FormOverview.cmd`（或 EXE 加 `--form-overview`）回退。该参数优先于原生参数。系统透明效果关闭或窗口失活时仍可能纯色降级，见[背景合成验证](native-backdrop-validation.md)。

管理器现在是任务栏上方的竖向游戏机面板，不占独立任务栏按钮。点击其他应用或右上角 × 会收起；双击托盘小显示器图标或选择“打开窗口画布”即可返回。底部方向键移动视角，中心键回原点，“返回”回到上一视角，“开始 / 暂停”和“总览”是圆形按键。面板大小、位置会按显示器工作区与 DPI 调整。

接管单位是整个应用窗口。浏览器或记事本中同一窗口的多个标签会一起移动；若只想把其中一个标签放到画布别处，先将它分离成独立窗口，再选择对应候选。记事本可能在已有窗口中新开标签，打开新文件不一定产生新窗口。

## 体验路径

1. 启动后核对底部显示“暂停”及托盘运行状态；移动前先登记恢复信息。暂停后点击“开始”接管所有符合准入条件的普通窗口，便签独立；候选与便签操作在“设备诊断 → 窗口候选”。
2. 将鼠标移到桌面空白处即可导航：滚轮纵移、Shift＋滚轮横移、左右双键拖动；单独右击打开 Windows 菜单。双键拖动不会在松开后弹出菜单。进入应用窗口直接点击和编辑。Home 返回原点，Backspace 返回整段手势起点；Esc 临时暂停自动导航，进入应用再回桌面后恢复。左键选择或框选桌面图标前先按 Esc。
3. 桌面空白处 Tab / Shift+Tab 打开空间总览，总览内再次按下返回；Ctrl+Alt+O 也可打开/关闭。搜索、选项与关闭位于下方工作区底座；输入标题筛选，方向键空间选择、Ctrl+Tab / Ctrl+Shift+Tab 轮选，Enter / 单击定位；Esc 同样取消。地图尝试显示全部可用预览，CRT 工作区显示对应视窗内的真实内容；离屏画面仍可能停帧。
4. 总览下方只显示自己保存的工作区：保存当前位置、筛选、右键重命名或删除，点击以约 150ms 镜头过渡定位到保存坐标；关闭动画时直接定位。不再附加默认“原点”卡片，Home 返回画布原点；已保存的同名工作区仍保留。尚未保存工作区时，可直接点“+”保存。需要处理损坏存储或批量管理时打开工作区旁的“•••”。工作区没有九槽限制，重启后保留。
5. 桌面 Ctrl＋滚轮轮选受管理的独立窗口；应用内 Ctrl＋滚轮交给应用。浏览器内部标签不会分别移动，需先分离为独立窗口。
6. 新开的普通窗口默认自动接入当前视角附近空位，不重排旧布局；“设备诊断 → 窗口候选”可关闭自动接入或手动加入其他候选。关闭一窗仅清理该窗，不暂停或恢复其余窗口；最后一窗关闭后空画布仍运行，保留视角并等待新窗。
7. “设备诊断”包含窗口候选、显示器与坐标、真实空间地图三个子页。可核对双屏缩放比例；混合 DPI 需先统一各屏缩放。
8. 收起管理器后画布继续运行。托盘图标为粉紫底、蓝色屏幕的小显示器，也可能位于任务栏“隐藏的图标”中。双击返回；悬停和右键菜单首行显示运行/暂停/待恢复状态，菜单可打开总览、设置、恢复中心、暂停并恢复或退出。底部“暂停”同样恢复接管窗口的原始位置。待恢复时退出会保留记录并明确提示；独立恢复过程中暂时禁止关闭和冲突操作，详见 `tray-control.md`。

“更多 → 外观”默认跟随壁纸取色，也可关闭跟随、重新采样或关闭“镜头与总览动画”。系统关闭客户区动画时也直接到位。取色只读取本地壁纸，不采集应用窗口颜色，失败则使用默认糖果色。详见 `console-and-wallpaper.md`。

屏幕外沿继续向外移动鼠标可推进镜头，停留不推进，相邻屏幕接缝可正常穿行；“导航与键位设置”可关闭并调整速度。Ctrl+Alt+C 或“更多 → 视角 → 准星模式”固定中心十字光标，持续移动镜头；单击和按住鼠标键不会退出，也不操作下方应用，Esc 或再次按组合键退出。准星不显示手动导航浮层，自动选择相对、绝对或普通鼠标兼容路径；“运行信息”的“准星输入”可查看当前路径。具体工具和仅有有限绝对坐标的限制见 `startup-and-remote-input.md`；边缘推进仍依赖相对输入。

桌面手势异常时先查看托盘是否仍在运行，以及“更多 → 运行信息”的输入接管启停、模式、钩子状态和最近退出说明。目录查询与原生移动事务不再临时撤销接管；开始/恢复时重建输入钩子，有持续相对鼠标移动而缺少钩子回调时会在安全边界重连。若画布已因目标窗口或恢复问题暂停，应按面板提示处理后重新开始。

启动唤醒已修正，不应再需要打开导航设置保存来激活输入。若存在旧恢复记录，主动作显示“恢复”并进入恢复中心；独立恢复确认完成后再点“开始”。不删除日志来绕过此状态。

Ctrl+Alt+P 或普通窗口标题栏右键切换便签，保持屏幕位置与原层级；取消便签从当前位置重新纳入。软件 `.lnk` 右键的“以画布便签模式打开”用于新建独立便签，Windows 11 可能需点“显示更多选项”。“更多 → 软件快捷方式右键入口”可移除该当前用户菜单。复用旧窗口、商店或不同 EXE 启动器可能不能自动识别，请对实际窗口用 Ctrl+Alt+P。详见 `pointer-and-sticky.md`，也包含准星退出和菜单移除说明。

手动导航模式及 Ctrl+Alt+Space 入口已移除。普通画布移动时短暂显示圆角、穿透鼠标的状态提示，停止后自动消失。“更多 → 导航与键位设置…”可配置手势、距离及六项键位：总览、准星、触控、便签、回原点和上一视角。全局组合要求 Ctrl+Alt（可加 Shift）配字母、数字或 F1–F11（不含 F4）；系统 Win 组合、Alt+Tab、编辑键、F12 等不接受。重复或已被占用的组合会显示错误并保留原键位；Tab 总览及 Esc 退出保留。

Ctrl+Alt+V 开启/关闭触控导航，也可从“更多 → 视角 → 触控导航 · 两指滚动”或托盘进入。模式内两指纵横滚动移动画布，单击、双击和按住拖动均交给应用，不再用左键拖动画布。深色半透明提示条只保留“双指平移”、总览/退出，Esc 同样退出，Home/Backspace 保留；菜单、任务栏及管理器保留自己的输入。Ctrl+滚动累计整格再轮选。原生接收器补充只发到目标窗口的滚轮消息，按钮期间透明，退出即销毁；具体触控板的滚动和点击仍需复验，见 `touch-receiver-and-window-lifetime.md`。“输入状态”可复制钩子/接收窗口计数。

## 恢复与文件

“更多 → 整理 → 平铺窗口…”先勾选并预览，确认后从当前主屏视角按行排列，保留原生尺寸、避开未选画布窗口。空间不足时向下延伸，可用总览定位。取消不移动窗口，“撤销上次整理”恢复整理前位置且不回退相机；移动/缩放相关窗口、暂停或退出后撤销失效。见 `region-arrangement.md`。

默认数据位于 `%LOCALAPPDATA%\BorderlessFlatWindow`：`recovery.json` 是恢复日志，`bookmarks.json` 是位置标签，`settings.json` 保存导航、接入和外观选择。不要把运行中的恢复日志当作可删除缓存；未恢复的失败记录需要保留以便重试。

原正常窗口的位置完全位于当前所有屏幕之外时，恢复会保留尺寸并放到最近屏幕的可用区域；部分仍可见的位置照原样恢复。目标位置、实际矩形或设备状态无法核验时仍保留记录，不宣称完成。见 `recovery-display-fallback.md`。

设置修改后立即生效并保存；“更多 → 本地设置”可重新读取或保存当前选择。只读或损坏时提示仅本次生效并保留原文件，初次读取失败不自动开始。正常启动会建立新画布会话，不恢复上次世界布局。可用 `--settings C:\path\settings.json` 指定独立文件，三个数据路径必须不同。详见 `local-preferences.md`。

主程序异常结束后，重启会进入恢复页；点击“启动独立恢复程序”，会自动寻找对应布局中的恢复工具。也可关闭管理器后直接双击 `Recover.cmd`，它与 GUI 无关。`Inspect-Recovery.cmd` 只显示待处理数量，不移动窗口。便携版恢复 EXE 在 `tools/recovery/`。恢复核验 HWND、PID、进程创建时间和独立实例标记，跳过已关闭/不匹配的目标，失败项保留。退出码 0 表示处理完成，2 表示仍待恢复，1 表示错误；损坏文件保留并报错。日志正被运行中的管理器使用时，先暂停或退出该管理器再恢复。

自定义数据位置可从终端运行。以下恢复 EXE 路径适用于框架依赖包；便携版改为 `.\tools\recovery\BorderlessFlatWindow.Recovery.exe`，或使用兼容两种布局的 `Launch.ps1`，见 `deployment.md`：

```powershell
.\BorderlessFlatWindow.App.exe --journal C:\path\recovery.json --bookmarks C:\path\bookmarks.json
.\BorderlessFlatWindow.Recovery.exe --inspect --journal C:\path\recovery.json
.\BorderlessFlatWindow.Recovery.exe --journal C:\path\recovery.json
```

## 当前限制与验收状态

系统切换现在会结束画布输入，在安全边界暂停并恢复；解锁、重连或设备重读后保持暂停，请检查显示配置再点击开始。世界布局、相机位置、历史和工作区保留，设备读取失败会禁止开始。消息回归未改变真实电源/会话，真实睡眠和拔插仍待验收，见 `desktop-lifecycle.md`。完整正式版缺口见 `release-v1-readiness.md`。

总览支持进出途中再次按 Tab / Shift+Tab 反向；主标签和诊断子页增加短淡入，关闭键扩大居中，文字不再随圆角裁切。用户已确认主面板、关闭键和留白通过，资源管理器选窗后重开总览的 Tab 焦点故障也已通过自然操作复验。

地图、搜索与工作区使用同一场景；工作区记录同一画布上的视角。选中窗口或工作区后立即交接，取消总览仍可反向。原生宿主使用系统背景与 DWM 实时预览，未嵌入 Windows 任务视图。

2026-10-21，用户远控体验 `BorderlessFlatWindow-show-3e1843d` 的原生总览后确认没有明显卡顿或渲染色块刷新，观感良好。远控环境的主观视觉验收已通过；本地实际帧时间、物理快速输入矩阵、多窗口长期运行和完整设备兼容继续验证。详细记录见 `native-overview-presenter.md`。

- 最大化、全屏、置顶、最小化、所属/工具窗口、其他虚拟桌面或无法验证身份的目标不在当前接管范围；关联弹窗或移动失败会暂停并恢复。
- 离屏 DWM 画面可能停留在旧帧；原生窗口返回视口后可继续操作。总览不承诺持续实时刷新，不向缩略图转发编辑输入。
- 标签与导航、自动接入、外观选择跨重启保存；窗口世界布局目前只在本次管理器进程有效。
- 备用导航组合可在设置中选择，Home/Backspace 和桌面 Tab 仍固定；全部导航键自由重绑定留在后续。UI 长时间阻塞的看门狗整体压力验收尚未完成。
- 同 DPI 多屏已有投影、平移和恢复模型检查，用户已确认真实双屏能开始并平移；完整设备组合、混合 DPI、拔插、休眠、管理员应用、输入法、广泛第三方应用及性能矩阵尚未完成。
- 用户已确认桌面右击、菜单关闭后滚轮、双键松开不误弹菜单、Backspace 整段返回、托盘图标及返回、文字完整性、竖向面板和工作区视窗裁剪通过；更广设备组合继续验收。
- 外观跟随和动画开关保存在本机；动态视频壁纸不保证提供可采样图像，远程文件不主动读取。壁纸路径、像素及总览快照不写入诊断日志。
- 滚轮/键盘导航、总览/原生输入、标签重启、新窗接入和故障恢复已有实测；本包已验证系统计算器、独立生成文本记事本及 Probe 四窗会话，并实际从 GUI 启动相邻恢复程序找回四窗。用户已确认 Shift＋滚轮、双键持续拖动和整段返回、任务栏找回后输入及悬停预览显示通过；预览持续刷新未作保证。
- 当前为私有项目内部试用，未确定正式发布许可证、签名、安装器或自动更新；托盘已提供。

源码构建：`scripts/package-trial.ps1 -NativeChecks` 生成框架依赖包；加 `-SelfContained` 生成便携包，可用 `-RuntimeVersion 10.0.13` 明确补丁。Release 检查后生成新目录与 ZIP，不覆盖已有产物，自动核对全部文件哈希、运行模式与许可入口。正式交付以 manifest 和对应版本的实际验证记录为准，打包成功不等于未验证条件已经通过。
