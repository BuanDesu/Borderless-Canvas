# 运行中新窗口接入

2026-10-19 反馈改进：当前操作以[自动导航、多屏与工作区说明](interaction-refresh.md)为准。本文保留早期阶段的实现和验证证据；其中单屏限制、手动模式、独立标签页及默认关闭自动接入的描述属于旧版。

FR-02，2026-10-18。支持在同一运行中会话加入普通窗口，保留既有世界布局、相机、历史、标签与窗口身份；不需要暂停并重新创建画布。任务见 [Issue #24](https://github.com/BuanDesu/Borderless-Flat-Window/issues/24)。

## 使用

1. 在“窗口画布”选择初始窗口并开始。候选目录随 WinEvent 更新，已接入项标为 `[已接入]`，不能在运行中取消勾选。
2. 勾选其他 `[可接入]` 窗口，点击“将勾选新窗口加入画布”。可手动加入之前未选择的窗口；身份改变或目标关闭须重新选择。
3. 可选“自动接入之后新开的窗口”，默认关闭，设置仅本次进程有效。开启时记录现有桌面基线，之前未选中的应用不会顺带接管；关闭后新窗只进入候选目录。
4. 新窗口保留接入时原生尺寸，优先完整放进当前视口空位，间隔 16 个画布单位。无完整空位时放在附近，可通过总览找到；不压缩或重新排列已有窗口，不自动抢焦点。
5. 等待当前移动、全局导航或总览结束后自动接入。正常暂停/退出恢复每扇窗口各自接入前的位置；同选择继续会话保留世界布局。

仅接入满足既有单屏、已知 DPI、普通窗口规则的目标。最大化、全屏、置顶、所属/工具窗口、其他虚拟桌面、最小化和无法验证的目标仍受准入限制。自动接入等待身份、标题和边界稳定至少 200ms；持续变化的窗口可能延后，可关闭自动接入后手动选择。初始身份未知或事件溢出时保守重建基线，宁可要求手动选择。

## 实现与失败处理

`NearbyWindowPlacement` 对既有矩形边界和视口候选行扫描空闲区间，先寻找视口内位置，再寻找附近位置；顺序确定，逐一占用新空位，没有固定窗口槽位。无有限且可映射的位置则拒绝接入。大规模布局性能留待 T12 测量。

`RuntimeAdmissionTracker` 区分原有桌面与之后的目标，使用原生 HWND/PID/进程创建时间和目录 ID。目录重置引起的 Guid 改变不会把同一原有窗口误认成新窗口；已验证销毁或进程身份改变才允许重新判断。WinEvent 回调只排队销毁提示，UI 对新增待定 HWND 短时复查，没有持续全桌面轮询。

`ManagedCanvasSession.AddWindows` 先验证整个选择，再为全部新增目标写入当前恢复日志和实例标记，最后提交只包含新增目标的原生移动批次。旧窗口不重新登记、规划或移动；世界尺寸使用接管时原始 placement。原生接受请求后仍需通过实际位置确认，不能以 API 成功代替落位。同步部分拒绝/登记失败会暂停恢复全组，并撤销新增逻辑项；迟到移动超时则保留有效世界布局供恢复后继续。读取原生状态时重入退出，会延迟释放所有权并取消接入，避免恢复登记中途丢失。

恢复读取还显式处理 `InvalidDataException`：损坏日志不被覆盖，不以未处理异常结束独立恢复入口，退出码为 1。文件检查从独立恢复 EXE 验证错误路径。

## 验证

`scripts/check.ps1 -Configuration Release -SmokeUi -NativeChecks`：191/191 模型、7/7 恢复文件、8/8 标签文件、48/48 原生检查，构建 0 警告、0 错误。新增覆盖空位/视口满/远坐标/无效几何、基线/稳定/身份复用、仅新增批次、相机历史标签不变、登记失败/部分拒绝/读取时退出，以及真实晚加入窗口和超时恢复。

本机 Windows 11、2560×1440、工作区 2560×1368、144 DPI（150%）的主程序实测只选择自有 Probe：

- 初始一窗、相机 `(240,0)`，开启自动接入后启动第二个 Probe，其两窗加入，管理数变为 3；原先未选的第一组 Source 仍未接管，原已管理窗口屏幕矩形前后相同。
- 手动加入第一组 Source，管理数变为 4；关闭自动接入再启动第三组，两窗只列为候选。手动选其 Source 后变为 5，相机仍为 `(240,0)`，其原生编辑框可输入测试文字。
- 暂停五窗后日志清空，第三组 Source 恢复 `(76,76)`、440×310；继续同一选择后仍为五窗和原相机，重新登记五项。
- 核验主程序进程路径和五项日志均属于三组自有 Probe 后强制结束管理器。独立 inspect 报告 pending=5、armed=5；重启主程序自动进入恢复页并显示五项。独立恢复 EXE 报告五项 `Restored`、`Remaining=0`，恢复页刷新为零，Source 测试文字保留且位置恢复 `(76,76)`。随后正常关闭所有实验窗口。

本地报告位于 ignored `artifacts/manual-runtime-admission/` 和 `artifacts/runtime-admission-check.log`，不提交桌面截图或用户标题。该证据覆盖自有跨进程窗口和主 GUI 故障流程，不代表普通第三方应用、物理 Shift/双键手势、任务栏实际点击/hover、多屏或性能矩阵已完成。
