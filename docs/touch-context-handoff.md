# 触控板双指右键与桌面菜单交接

2026-10-25。核对并直接启动正式构建 `2c212b3` 后，用户确认真实画布双轴移动已恢复；但桌面空白处的触控板双指轻点需要多次才弹出右键菜单，顶部触控条仍然存在。接收层命中修正有效，菜单交接尚未通过。

## 本轮修正

上一版点击后约 100ms 恢复接收，桌面移入还会请求接收层焦点。双指轻点后的轻微指针移动可能因此在 Windows 异步打开菜单时再次激活接收层。

现在仅在进入触控模式或用户点击提示条标题时请求焦点，指针在桌面移动不再自动激活接收层。右键按下和抬起均透传，并把该次点击的透明交接期保留至少 500ms；其他按钮仍为 100ms。后续按钮不会缩短已经存在的交接期，按住期间和系统菜单打开时均不重新接收。菜单结束后恢复原滚动接收路径。

保留真实客户端命中、进入时的焦点请求、纵横轴精度与 Shift/Ctrl 语义，不恢复左键拖动画布，也不向桌面重放双指轻点。

## 验证边界

新增隐藏自有接收器检查先复现点击后过早重新接收，再验证延迟菜单、菜单期间持续穿透、关闭后恢复和后续水平小增量。它进入默认 CI，不安装输入钩子、不注入桌面点击。Release 332 模型、24 文件、104 原生检查，以及 UI/完整原生总览通过，构建无警告或错误。

用户的正式版两轴移动结果作为已通过证据保留；本轮桌面双指右键、应用点击与菜单关闭后的连续滚动仍需实体复验，不能用隐藏消息检查代替菜单实际行为。
