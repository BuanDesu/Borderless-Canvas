# 便携试用版兼容范围

支持 Windows x64。多屏使用前请将各屏设置为相同缩放比例；混合 DPI 目前不接管。

- 普通窗口会自动加入画布；没有窗口时画布也保持运行。
- 管理员权限、置顶、最大化、全屏、关联弹窗及部分特殊应用仍有兼容限制。
- 应用最小化时保留其世界位置并暂停该窗移动；从总览直接恢复最小化窗口，以及最大化/全屏的完整状态支持仍待完善。
- 离屏预览可能停帧，不保证每个应用离屏时持续更新。
- 触控导航支持双指纵横滚动；不同设备和远控输入仍需各自验收。
- 书签和设置可保留，窗口世界布局目前只在本次运行中保留。

出现异常先从托盘“暂停并恢复窗口”；重新启动显示待恢复时按提示处理。必要时退出管理器，再运行包内 `Recover.cmd`。不要删除未处理的恢复记录。

这是预发行试用版。使用说明见包内《试用说明.md》，版本见 `VERSION.txt` 与运行信息中的构建标识。更新时先暂停恢复并退出旧版，再完整解压新版到新目录。
