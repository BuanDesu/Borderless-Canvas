# 触控板、触屏与输入状态

## 高精度触控板

桌面兼容滚轮消息到达钩子时，纵向/横向滚动分别沿两轴移动画布；普通模式下应用内仍由原应用处理。纵横滚动保留小增量，在相同帧合并为一次镜头请求。触控导航明确切换到跨应用的滚动路由，取消单击/拖动捕获；不同驱动可能将手势直接发送给目标窗口，不能保证钩子都能接收，仍需设备复验。

Ctrl+滚动用于逐个轮选窗口。原实现把每个不足一格的滚轮消息也算一次切换，会使触控板连续跳过窗口。现在累计正负增量，达到 120 单位才切换一次；小增量不再放大，普通鼠标每格保持一次。400ms 无输入、时钟回退、Ctrl 松开、退出画布导航或改为普通滚动会清除余量。每个消息最多处理十二次，超出的整格不延后追赶。

微软说明精密触控板可产生小至 delta=1 的滚轮消息，应用需处理这些增量，见 [Windows precision touchpad devices](https://learn.microsoft.com/en-us/windows/win32/w8cookbook/windows-precision-touchpad-devices)。本项目使用现有兼容滚轮消息，没有要求较新或预发布的触控板 API，也不更改系统三指/四指手势。

## 容易找到的本地诊断

右击托盘图标 → **输入状态…**；或主面板 **设备诊断 → 窗口候选 → 输入状态**。主面板“更多”里也保留同一入口。

窗口显示接管启停、当前模式、钩子状态、准星输入来源、通知消费状态与最近退出原因。内容可选中复制或点击“复制报告”，不自动写日志或上传。托盘入口在打开面板前截取状态，避免打开面板本身释放导航后丢失现场。报告是持续可关闭的非模态窗口，继承主面板置顶，不锁住主面板；关闭后不自动开始接管。改动背景与延时回归见[边缘与输入通知](edge-speed-and-input-notifications.md)。

用户使用网易 UU 远程，具体鼠标输入来源仍需新版“输入状态”复验；未核实其内部协议或具体客户端的相对输入设置，不能以隔离夹具代替该工具实测。绝对/普通坐标路径和有限客户端坐标的边界见 [启动与远控修正](startup-and-remote-input.md)。

## 仅滚动的触控导航

默认 Ctrl+Alt+V 开启/关闭，也可从主面板“更多 → 视角 → 触控导航 · 两指滚动”或托盘进入。两指纵向滚动、横向滑动移动画布；Ctrl+滚动累计整格轮选。六项键位可在“导航与键位设置”调整，Tab 总览和 Esc 退出保留。

按最新反馈移除整屏输入层和单指/左键按住拖动画布。单击、双击及按住拖动均直接交给应用；不再失焦即退出。只保留小型、不激活的工具条，提供总览、原点、返回和退出；菜单、任务栏及管理器保留自己的滚动。工具条本地消息和其他窗口的钩子路由互斥，不重放点击，也不限制光标。

进入工具条前等待输入线程确认模式，避免旧退出通知关闭新工具条。Esc、再次按组合键、工具条退出、总览、面板、暂停、恢复或显示/系统切换会结束模式并清理待处理输入。这里处理兼容滚轮消息，不从原始触屏接触合成两指手势；未发送滚轮消息的设备/驱动仍需适配。

## 检查范围

高精度轮选模型、两轴帧合并和设置文件检查保留。隔离输入 worker 验证应用上的两轴小增量、重复单击及完整左键拖动放行、菜单和应用 Home 原用途、Esc/暂停、准星交接、自定义上下文键；没有安装钩子、注入输入或限制用户光标。

自有透明工具条检查窄宽度布局、滚动与按钮命令以及不激活前台。界面/系统边界检查只使用未显示夹具，验证释放和队列清理。用户此前已反馈旧触控模式及 UU 准星正常；新“仅滚动”语义的触控板点击、物理改键和不同驱动仍需复验。详见 [工作区与导航更新](workspace-input-refresh.md)。
