# 触控板、触屏与输入状态

## 高精度触控板

桌面兼容滚轮消息到达钩子时，纵向/横向滚动分别沿两轴移动画布；应用内仍由原应用处理。已有的纵横滚轮消息保留小增量，在相同帧合并为一次镜头请求。但不同驱动/系统可将触控板滚动直接发送给目标窗口，不能保证钩子都能接收。用户已报告桌面两指滚动/横滑不工作，为此增加下述具有明确消息目标的触控导航入口。

Ctrl+滚动用于逐个轮选窗口。原实现把每个不足一格的滚轮消息也算一次切换，会使触控板连续跳过窗口。现在累计正负增量，达到 120 单位才切换一次；小增量不再放大，普通鼠标每格保持一次。400ms 无输入、时钟回退、Ctrl 松开、退出画布导航或改为普通滚动会清除余量。每个消息最多处理十二次，超出的整格不延后追赶。

微软说明精密触控板可产生小至 delta=1 的滚轮消息，应用需处理这些增量，见 [Windows precision touchpad devices](https://learn.microsoft.com/en-us/windows/win32/w8cookbook/windows-precision-touchpad-devices)。本项目使用现有兼容滚轮消息，没有要求较新或预发布的触控板 API，也不更改系统三指/四指手势。

## 容易找到的本地诊断

右击托盘图标 → **输入状态…**；或主面板 **设备诊断 → 窗口候选 → 输入状态**。主面板“更多”里也保留同一入口。

窗口显示接管启停、当前模式、钩子状态、准星输入来源与最近退出原因。内容可选中复制，不自动写日志或上传。托盘入口在打开面板前截取状态，避免打开面板本身释放导航后丢失现场。弹窗拥有主窗体，关闭后不自动开始接管。

用户使用网易 UU 远程，具体鼠标输入来源仍需新版“输入状态”复验；未核实其内部协议或具体客户端的相对输入设置，不能以隔离夹具代替该工具实测。绝对/普通坐标路径和有限客户端坐标的边界见 [启动与远控修正](startup-and-remote-input.md)。

## 单指触控导航

画布开始后，点击主面板 **更多 → 视角 → 触控导航 · 单指拖动**，或托盘右键的同名入口。进入后在任一显示器工作区单指按住拖动画布；也支持普通鼠标或远控传入的左键拖动。工具条可点“总览”“原点”“返回”（上一视角）“退出”，不依赖物理键盘。Esc 退出、Tab / Shift+Tab 打开总览；退出或切换到其他应用后再操作应用。

临时输入层只覆盖显示器工作区，不覆盖任务栏；不限制/隐藏光标，不设为始终置顶。它接收发送到自身窗口的纵横滚动消息，因此触控板可以两指纵横滚动；Ctrl+滚动使用同一整格累计规则。该路径与全局鼠标钩子互斥，避免重复累计。窗口会阻止模式内的接触落到移动到手指下方的应用；退出后恢复普通应用触控和桌面长按右键。

单指接触通过 Windows WM_POINTER 读取物理坐标（触屏/笔），同一次接触保持同一身份；额外手指不接替手势，不做缩放。触控生成的兼容鼠标消息不重复累计；仅有普通鼠标消息的远控可走左键拖动。抬手包含最后一段移动，取消不跳到其他手指位置，长时间停留不拆分返回历史。依据 [WM_POINTERDOWN](https://learn.microsoft.com/en-us/windows/win32/inputmsg/wm-pointerdown) 的隐式接触捕获，接触仍归原输入层直至结束。

退出按钮、失焦到其他应用、打开总览/面板、暂停、恢复、显示/系统切换和应用退出都会释放输入层。输入按帧消费，目录读取或原生事务中先排队；溢出则暂停恢复。该模式是明确进入的兼容入口，没有实现全局透明接触转发，也未更改 Explorer 或全局触屏/三指手势。

## 检查范围

模型覆盖 delta=±1/±40/±120 的等量轮选、反向抵消、间隔/退出边界、零值和批量上限，以及小增量两轴按帧合并、单指历史/抬手/拒绝、接触所有权/取消。第十二组隔离 worker 复用生产钩子路由验证 Ctrl 小滚动不泄漏给 Explorer、不跳窗，Ctrl 松开清余量，横向与纵向保留符号和数值。

自有 UI 检查验证托盘入口的只读快照和模态所有权；向自有隐藏 HWND 发送滚动消息（包括消息自带的 Ctrl 修饰位），验证横轴与小增量；在不激活、全透明的自有工具条检查窄宽度布局与按钮命令。系统/恢复/面板/暂停边界只使用未显示的输入层与合成接触，确认释放及清队列。没有进入用户桌面的真实全屏触控模式，也没有注入触屏或限制用户光标；WM_POINTER 硬件驱动、实体触控板、UU 远控自然操作仍需试用复验，不能把路由夹具当成硬件实测。
