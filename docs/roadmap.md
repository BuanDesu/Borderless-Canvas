# 开发路线图

里程碑描述交付范围，不是工期承诺。只有完成退出条件才标记完成。

| 阶段 | 状态 | 交付 | 退出条件 |
| --- | --- | --- | --- |
| M0 基础项目 | 已完成 | 分层解决方案、模型预览、只读枚举、文档和模型检查 | 解决方案构建通过、模型检查通过、桌面壳离屏渲染通过 |
| M1 只读桌面映射 | 未开始 | 窗口准入规则、稳定身份、显示器工作区、事件监听、只读空间地图 | 自身/桌面/任务栏/其他虚拟桌面不被误纳入；创建关闭与拖动可跟踪 |
| M2 原生画布平移 | 未开始 | 恢复日志与恢复入口先落地，再做单屏窗口移动、平移手势、原点与焦点导航 | 接管失败可恢复；同位移、尺寸不变；从任务栏激活离屏窗口可找回 |

| M4 兼容与打包 | 未开始 | 多屏混合 DPI、拔插恢复、常用应用矩阵、性能分析、托盘与发布包 | 验收矩阵通过；无窗口遗失；记录版本和可复现性能数据 |

## 下一步任务

1. 在 Windows 适配器定义 WindowIdentity 与准入原因，补齐 DWM cloaking、owner/tool window、其他虚拟桌面的只读筛选。
2. 引入会话快照与独立恢复入口，先在测试窗口上验证 HWND 复用和原进程关闭的处理。
3. 明确首个显示器工作区、DPI 换算及离屏方案，验证窗口不会漏到副屏。
4. 只接管几个可恢复的测试窗口，实现一次事务的批量平移，再接入真实应用。
5. 把地图交互与工作相机分离，增加选择状态、取消与空间方向邻接。

不先增加应用内容缩放、虚拟桌面桥接、复杂插件系统、开机自启或联网更新。先确认真实窗口平移、空间地图和恢复组成的闭环。
