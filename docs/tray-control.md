# 托盘状态、设置与恢复

收起主面板后，托盘小显示器图标仍保留。悬停提示和右键菜单首行显示“就绪”“运行中 · N 个窗口”“已暂停”“待恢复”或“正在恢复窗口”。这里只使用状态和数量，不包含窗口标题、应用身份、相机坐标或文件路径。频繁的相机状态通知会比较展示快照，不向 Explorer 重复发送相同提示。

菜单提供打开画布、空间总览/返回画布、暂停并恢复、恢复中心，以及设置子菜单。导航手势直接打开现有设置弹窗；取色与动画、本地设置打开主面板中的同一菜单，使用相同配置和保存逻辑。暂停和总览仅在画布运行时可用。独立恢复正在处理时允许查看面板和恢复中心，设置、再次暂停、开始画布及用户关闭/退出保持禁用，等待进程结束。

从总览打开面板、设置、恢复中心或退出时，先取消请求和准备，再等待正在显示的总览完成关闭。目标只保留最后一次选择；面板动作排到总览焦点恢复之后的下一次 UI 分派，避免完成回调把焦点重新切走。没有新增后台轮询计时器。导航设置使用真实顶层窗体作为模态 owner，继承置顶属性；编辑期间暂停导航和预热，结束后恢复可用状态并清理旧导航请求，输入故障仍触发恢复。

## 恢复状态

运行中的管理器持有日志写入租约，此时“检查日志”遇到占用不能把正常运行误报成恢复失败。托盘刷新本身不读取日志；启动、明确打开/检查恢复中心、恢复处理和管理状态切换才读取。

恢复失败或检测到旧会话后，重复暂停不会把“待恢复”覆盖成“已暂停”，也不会销毁剩余记录。退出入口相应显示“退出（保留恢复记录）”。未开始的会话不会因为一次暂停而声称完成恢复。

独立恢复入口启动前重读日志并固定该批记录 ID。进程退出后严格解析报告，核对退出码、必填字段、结果枚举、失败数量、重复 ID 和原批次覆盖；完成报告加上日志为空才通知管理会话再次取得租约核验。会话确认后保持暂停，不自动接管。仅有文件消失、空日志、部分/过期报告或读取失败都不能据此清除运行会话的“待恢复”。

## 验证范围

模型覆盖托盘状态优先级、运行租约、模态/恢复忙状态、总览请求和提示长度，并覆盖继承/失败日志上的重复暂停、过期完成报告、再次读取失败和完成后仍暂停。默认检查现为 273 项模型、23 项存储；交互桌面另有 59 项原生检查。

透明 UI 夹具通过真实托盘菜单命令打开共享设置、选择恢复页；模拟总览准备堆栈，验证取消、保留最后目标、完成后延后显示；100 次相同通知保持展示快照不变。实际导航设置模态循环验证顶层 owner、禁用/恢复、置顶、保存和取消，没有发送全局输入。

另一独立目录写入一条合成未完成登记记录，实际启动恢复 EXE，验证忙状态、禁止用户关闭、完整报告、释放后的空日志和重新可用。该记录没有有效的桌面目标，恢复不会移动桌面窗口；夹具还拒绝缺字段和矛盾的结果。既有原生回归仍验证真正的自有窗口恢复。

这些检查不代替自然鼠标托盘菜单、Explorer 重启、多屏和长期兼容矩阵。此前用户已确认图标可见、双击返回及暂停恢复；本轮保持该图标。T11–T13 的其余兼容、性能、许可和正式发布条件继续开放。原始本地日志、设置和桌面图像不提交仓库。
