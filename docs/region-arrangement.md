# 区域平铺与撤销

“更多 → 整理 → 平铺窗口…”先显示位置预览。默认勾选中心位于当前各屏视区内的受管窗口，也可手选其他画布窗口；“显示整理前”可比较位置。预览不采集桌面、不移动真实窗口，取消保持原状。确认后从当前主屏视区左上方按行排布，保留 16 个画布像素间距。

整理保留窗口原生大小，避开未选的画布窗口，一行放不下就向下延伸，超宽窗口单独占行。原点、相机、导航历史与工作区不变；屏幕外的窗口可从空间总览定位。未接管的应用不参与布局，也不会被移动。

“撤销上次整理”只恢复最近一次整理前的世界位置，沿用当前相机投影。因此继续平移再撤销不会退回旧视角；撤销也可以恢复原来的重叠。空选择或无变化提交不消耗已有撤销。手动移动/缩放相关窗口、关闭或身份变化使撤销失效；标题、无关窗口位置变化和正常平移不使其失效。暂停、故障恢复和退出清除撤销，恢复仍返回开始接管前登记的位置。整理记录不持久化。

## 提交与恢复

`RegionTiling` 只做几何排布。只读 `CanvasArrangementPlan` 复制全画布来源几何和所选目标，绑定创建它的会话；提交要求全部来源集合和矩形仍一致，新增窗口或障碍变化均拒绝过期预览，标题变化不影响有效性。

编辑期间结束手势、暂停导航及空闲总览准备；模态 owner 使用实际顶层管理窗体，与置顶面板保持相同层级。确认后重新核验全部受管源，期间暂停、显示变化或会话被替换不能提交旧计划。退出编辑恢复可用性，晚到导航作废，故障仍触发恢复。

会话先投影全部目标，再只向已登记的所选身份提交移动批次；不重新登记、不改变恢复原位置、不激活或调整 Z 顺序。成功提交才发布新世界位置。部分拒绝保留提交前逻辑布局并暂停恢复全组；异步接受仍需原有 1500ms 观察协议确认，超时、意外位置或状态改变会暂停恢复。当前移动、编辑或总览未结束不能再次整理或撤销。

## 验证

`scripts/check.ps1 -Configuration Release -SmokeUi -NativeChecks -NativeOverviewChecks` 覆盖原有功能及新增回归：

- 固定障碍、混合尺寸、越屏延伸、负/远坐标、超宽窗口、非法输入与 160 组固定随机布局。
- 只移动所选、只读预览、导航后撤销、过期/外会话计划、等待/暂停/总览边界、部分拒绝、超时、外部编辑、无变化提交和移动回调重入退出。
- 自有原生窗口整理/平移/撤销后的尺寸、未选窗口、相机/历史/工作区、前台与背景/任务栏不变；暂停恢复日志清零。拒绝移动的自有窗口触发全组恢复并清除撤销。
- 默认 UI 检查渲染合成预览并核对默认选择；不能代替真实多屏或广泛应用验收。

实际管理器首轮预览发现 owner 指向子控件时可能被置顶面板遮挡，已改为顶层 owner 并对齐置顶属性。新增真实模态循环回归：从子控件调用同一 ShowFor，断言原生 owner 为顶层、置顶属性、owner 禁用及结束后重新启用；只向夹具 HWND 投递 Enter/Escape，验证确认、取消和空选择的 Enter 不关闭。前台保持不变。

桌面工具能打开真实预览，但不能把输入可靠定向到该嵌入模态框，因此没有把工具操作计为自然确认/取消验收。两次开发会话只接管自有 Probe，均未提交整理；独立恢复器核验恢复完成、pending/armed 为零。原始日志、窗口身份和桌面图像不提交仓库。

T12 的输入到实际呈现、GPU、多窗口长期资源与完整兼容矩阵继续开放。
