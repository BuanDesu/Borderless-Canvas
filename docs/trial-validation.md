# 本地试用产物与兼容验证

2026-10-19，基于 FR-02 后续集成。验证平台仍为 Windows 11 x64、2560×1440、工作区 2560×1368、144 DPI（150%）。验证只接管本次新开的计算器、分离后的生成文本记事本窗口，以及包内 Probe；其他应用和原有文档窗口保持未选。

## 产物

`scripts/package-trial.ps1 -NativeChecks` 先执行 Release、模型/文件、UI 冒烟及原生检查，再分别发布 App、Recovery、Probe，合并到新目录；同名依赖必须哈希一致。保留框架依赖 EXE、DLL 和 runtimeconfig，附启动/只读检查/恢复入口与中文指南，再生成 ZIP。目录与 ZIP 已存在时拒绝覆盖；不删除旧产物。

`manifest.json` 记录源码提交、已跟踪源码是否修改、构建时间、运行时要求、原生检查是否执行，以及每个载荷文件的 SHA-256。未提交的集成验证包明确标记修改状态，不能冒充某提交的精确产物。包需要 .NET 10 Windows Desktop Runtime x64；不包含运行时，不依赖 SDK、WSL 或仓库开发路径。

首次集成目录 `artifacts/trial/integration-20261019`：25 个载荷文件，逐项校验零失败，ZIP 生成成功。实际从产物目录启动 GUI、Probe 和独立 Recovery EXE；恢复页从相邻目录启动恢复程序，无需开发目录回退。提交后重新生成最终试用目录，路径记录于本地构建报告；产物不进入 Git。

## 用户人工验收

2026-10-19，用户在 `6d756ed` 最终试用目录上亲手操作并回复：

- 进入导航后，按住 Shift 滚轮能够横向平移。
- 按住左右键能够连续平移；松开后一次 Backspace 回到整次拖动起点。
- Source 离屏后，Esc 退出导航，从任务栏选择 Source 能找回并输入。
- 任务栏悬停显示预览窗口；用户已暂停并恢复原位。

这是用户直接反馈的真实鼠标与任务栏证据，补齐工具无法代操作的路径。正常桌面账户随后只读确认默认恢复日志 pending=0/armed=0，主 GUI 显示“已暂停”、管理 1 个 Source，其他候选未选择。用户没有确认任务栏预览持续刷新，因此只记录“可显示”，不宣称离屏实时画面。
