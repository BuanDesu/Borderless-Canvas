# 指针导航与便签窗口

2026-10-23。本轮修改初始接管范围及便签语义；旧文档中“先勾选、开始前未选窗口始终排除”的描述保留为历史记录，以本文为准。

## 接管与固定

正常启动仍保持暂停，点击“开始”后接管当前所有满足准入规则的普通窗口；随后新建的普通窗口默认自动接入。最大化、最小化、全屏、置顶、工具/所属窗口、其他虚拟桌面及身份无法验证的目标继续排除。写入窗口标记被系统以权限不足拒绝时，仅跳过该目标；只有确认登记已回滚后才继续，不能把其他恢复故障当作可忽略的权限问题。

主页面移除候选列表；“设备诊断 → 窗口候选”保留检查、手动加入、自动接入开关和便签操作。暂停后再次开始保留匹配窗口的世界位置和相机，新加入窗口按当前物理位置换算，不重建旧布局。

**Ctrl+Alt+P** 切换当前焦点窗口的便签状态。普通窗口标题栏右键的系统菜单也包含“固定为画布便签 / 取消画布便签”。按用户选择，便签固定在屏幕当前位置，画布移动时不跟随，保留原有层级；不会强制置顶。取消便签从当前物理位置回到画布，避免瞬间跳回旧世界位置。

固定操作先等待尚未完成的移动落定，再移除该窗口的恢复所有权和世界记录；不在固定时移动或激活窗口。便签已明确退出恢复范围，因此暂停/退出不会把它送回接管前的位置。窗口内的便签标记随管理器退出保留，随窗口销毁消失；不保存窗口名称、身份列表或路径文件。标题栏菜单只移除自己的带标记项目，不重置目标菜单，也不注入或替换其他进程窗口过程。自行绘制、不显示标准系统菜单的应用可用快捷键或诊断入口。

### 从软件快捷方式启动便签

正常运行时提供当前用户的 `.lnk` 右键菜单“以画布便签模式打开”；Windows 11 可能位于“显示更多选项”。“更多 → 软件快捷方式右键入口”可关闭并移除入口。

只读取所选 `.lnk` 的本地 EXE 目标，不调用链接 Resolve，不修改链接；启动仍交给原快捷方式，保留参数和工作目录。现有管理器通过限长、同用户和同会话的命名管道接收请求；没有实例时启动管理器，仍不自动开始画布。安装范围仅为 `HKCU\Software\Classes\lnkfile\shell\BorderlessFlatWindow.Sticky`，不修改默认打开方式，不请求管理员权限。

启动前记录已有窗口身份，并将随后出现、目标 EXE 相符且稳定的新窗口暂时排除出自动接入，匹配后设为便签。请求有 30 秒期限及数量上限，不按窗口标题猜测，不将已有窗口误当新便签。已打开的单实例应用若仅复用旧窗口，或启动器产生不同 EXE、Store/别名链接无法解析出本地 EXE，此入口可能无法自动匹配；此时使用 Ctrl+Alt+P 固定实际窗口。请求超时不继续持有排除项。

升级时从新目录启动会更新该入口路径；移除应用前先关闭此选项，再暂停并退出。若未移除旧入口就删除目录，入口可能残留；可运行另一份有效包关闭此选项。该入口不是全系统安装项。

## 镜头轮切

桌面空白处 Ctrl+滚轮轮选受管理窗口，使用约 150ms 的平滑镜头位移，实际窗口保持原生尺寸。连续轮选从当前镜头位置重定向，整次轮选只保存一个返回起点；目标到位并核验后才请求焦点。手动平移、总览、暂停及失去交互条件会结束过渡。应用内部 Ctrl+滚轮继续交给应用。

“更多 → 外观 → 镜头与总览动画”或系统客户区动画关闭时直接到位，不强制播放动画。此为调度时长，不是已测得的物理输入延迟或呈现帧率。

## 屏幕边缘推进

默认开启，可在“导航设置”关闭并调整鼠标速度。鼠标抵住显示器的外侧边缘后，继续向外移动才平移视角；单纯停留不移动、向内移动或在两个相邻屏幕的接缝穿行均不触发。按住鼠标键或 Ctrl/Alt/Win、打开原生菜单、总览或模态框时不推进。

通过 Windows Raw Input 读取相对位移，保留传统鼠标输入，不用反复重置指针模拟边缘速度。缺少相对位移的远控、触控或绝对坐标设备不能保证此功能，仍可使用滚轮、Shift+滚轮及双键拖动。

## 准星模式

点击“更多 → 视角 → 准星模式”或 **Ctrl+Alt+C**。这是独立于手动导航的锁定模式，只显示中心十字，不出现手动导航浮层。光标保持在当前显示器中心，相对鼠标位移持续移动镜头，类似第一人称游戏的视角控制；单击和按住鼠标键都保持模式，按下/松开成对拦截，不点击中心下方的应用。**Esc 或再次按 Ctrl+Alt+C**退出，恢复进入前的鼠标位置及限制范围。

准星模式会显式限制鼠标；只在画布运行、无总览/菜单/鼠标按键且退出键能注册时进入。失焦、原生菜单、暂停、系统切换、显示配置变化、输入看门狗或关闭都会释放。若其他应用已经更改鼠标限制，不覆盖其新限制。现在支持绝对 Raw Input 的连续坐标差，并在只有普通移动消息时转为兼容路径，不再仅因缺少相对移动就退出；具体远控及有限绝对坐标的边界见[启动与远控修正](startup-and-remote-input.md)。

### 输入接管与退出原因

2026-10-23 修正：短暂的目录查询和原生移动事务只暂缓 UI 消费，保留全局输入资格；设置/整理模态、面板交接、恢复、系统切换或暂停才停用。桌面第一次鼠标按下不会因为异步按键状态已更新而被误认为来自应用的拖动。输入线程发布实际可用状态，UI 与之核对，不只依赖自己的旧缓存。

每次开始/恢复输入会重新建立键盘与鼠标钩子。微软说明低级钩子超时可能被静默移除，见[鼠标回调说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)。若持续收到相对鼠标移动、却长期没有鼠标钩子回调，等待按键释放且无菜单/总览后有界重连；不定时抢占钩子顺序，不向其他应用发送探测键或点击。此机制覆盖有相对鼠标数据的中断证据，不能证明用户此次间歇故障的唯一原因，也不能检测所有设备或仅键盘钩子丢失的情况。

托盘右键“输入状态…”、设备诊断 → 窗口候选 → 输入状态，以及“更多 → 输入状态…”显示输入接管启停、当前独立模式、钩子建立/重连状态及最近的导航退出说明。托盘打开前保留状态快照，内容可选择复制。从“更多”启用准星会等待原生菜单关闭后才进入；重复切换、暂停、其他模式或等待超时取消这次请求，不在菜单仍打开时限制鼠标。画布自动暂停时仍需先处理提示再开始；没有把暂停状态伪装成输入正在接管。未增加后台日志、窗口内容采集或上传。

## 验证边界

模型覆盖外缘/接缝/负坐标、连续输入历史、轮切中间帧和重定向、固定/取消固定及日志失败、全量接入和权限拒绝、启动请求的基线/稳定等待/期限。原生检查使用自有窗口核验实际移动、固定后独立、跨进程系统菜单的保留与清理、窗口标记、Raw Input 注册及相对/绝对包解析、原快捷方式读取及未启用接管时的钩子重建。十二组隔离输入线程检查复用真实路由函数，覆盖桌面手势/应用透传、准星相对与远控坐标兼容、退出/源切换、钩子时序、菜单进入、启动唤醒重试和精度轮选；进入默认 CI，不安装钩子或限制真实光标。UI 检查验证查询期间的输入资格、真实安全边界、无画布子句柄的主窗体投递、准星浮层不激活窗口、命名管道及 SVG 布局。触控导航和明确的硬件边界见[触控说明](touch-and-precision-input.md)。

自动检查不进入真实准星模式，不锁住用户或远控指针，不安装真实快捷方式菜单，也不启动用户软件。边缘操作手感、实际准星退出、物理快捷键/标题栏选择、Explorer 快捷方式及不同启动器的自然操作仍须在试用包补齐。源码与文档不包含桌面图像、个人路径或窗口身份数据。
