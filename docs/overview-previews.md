# 总览预览与降级（T09）

当前行为已在[总览合成修订](overview-compositor.md)更新：取消默认 16 项和离屏/重叠过滤，加入真实 CRT 工作区裁剪预览及资源复用。下文保留 T09 的初次验证记录，不代表当前过滤策略。

2026-10-18。空间卡片始终保留标题、相对位置和原生尺寸比例；DWM 画面是可关闭的附加内容，不参与窗口选择和导航判定。

## 操作和降级

- 总览底部“窗口预览（可能停帧）”可切换画面。关闭后立即释放资源，卡片仍可搜索、方向选择、单击或 Enter 定位。
- 完整位于当前工作区内的窗口可以提供画面。离屏停放或跨越工作区边缘的窗口直接使用标题视图，避免把先前验证过的离屏旧帧当作当前内容。
- 卡片太小、超出地图、与其他窗口卡片或原点标记重叠时使用标题视图，保持几何和文字可辨识。画面在标题与状态文字之间等比例适配，不拉伸卡片，也不改变其世界位置。
- 同时最多注册 16 个预览，优先选中窗口；其余卡片仍可选择。这个限制只约束 DWM 资源，不限制窗口、位置标签或画布范围。
- 注册失败、来源尺寸不可用、更新失败或身份失效时降级。失败按模型 ID 和原生身份缓存，不在每次事件中反复注册；F5 /“适配 / 重试”显式重试。
- 屏内画面也可能静止、受保护或停止刷新。DWM 成功不能证明像素新鲜度，也无法仅凭静止画面区分“应用没有变化”和“已经停帧”。标题始终保留，用户可以关闭画面；本阶段没有自动像素变化检测或截图缓存。

预览没有原窗口的交互控件，不向来源转发点击、键盘或滚轮。点击画面中的输入框图像会确认定位；编辑操作在定位后的原生窗口进行。

## 生命周期与边界

`OverviewPreviewSession` 位于 Application，通过端口管理注册、比例适配、资源上限、失败缓存和释放。搜索排除、目标退出、身份替换、预览关闭、总览关闭及主承载 HWND 销毁都会释放对应资源。重入保护覆盖原生查询期间嵌套刷新或关闭；注册返回太迟时也立即释放，不复活关闭的总览。

Windows 端口在注册前检查 HWND/PID/进程启动时间、可见性、cloak 和当前虚拟桌面，并设置独立的临时 GUID/随机值窗口属性。查询和更新前校验属性与身份，释放时只删除自己的属性；不能设置属性的来源降级。该标记不授权移动或激活窗口，不依赖恢复日志中的所有权。

嵌入式总览自身是子窗口；DWM 的目标使用本进程真正的顶层主窗口。卡片内容位置通过 `PointToScreen` / 顶层 `PointToClient` 换算到目标客户区，释放发生在恢复主窗口样式之前。DWM 自行合成画面；没有新增持续全桌面轮询、屏幕抓取或 Paint 中注册资源。

接口依据：[DwmRegisterThumbnail](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmregisterthumbnail) 要求顶层目标且由调用进程拥有；[DWM_THUMBNAIL_PROPERTIES](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ns-dwmapi-dwm_thumbnail_properties) 定义目标区域、可见性和来源区域。原生成功与实际刷新分别验证。

## 验证记录

- 最终 Release 构建 0 警告/错误，153/153 模型、6/6 文件、45/45 原生检查及总览承载渲染通过，见[验收记录](acceptance.md)。模型覆盖失败隔离、关闭、搜索、禁用/重开、身份替换、比例、上限、失败重试及原生回调重入。
- 原生透明 fixture 验证子视图使用顶层目标、注册/尺寸/更新、关闭和失效身份；不把透明测试或 HRESULT 成功当作像素刷新证明。
- 本机单屏 2560×1440、工作区 2560×1368、150% DPI。仅勾选自己的跨进程不透明 Probe Source；在真正主窗口总览内观察画面序号从 277 到 338，并在重开/清除搜索后看到 447、618。缩略图位于卡片内部，标题、原点和视口框正常。
- 关闭预览后同一位置显示“预览关闭 · 标题视图”，再次开启恢复画面；无匹配搜索为 0/1，画面释放且卡片原位变暗；清除搜索回到 1/1。
- 点击缩略图中的输入框图像，总览关闭、相机定位到 (-1022,-491)，原窗口输入内容仍为初始测试文本。一次 Windows 拒绝激活的状态明确可见；另一轮离屏定位已成功请求激活，没有把“请求”写成强制保证。
- 返回原点后滚轮移到 (0,1200)，管理状态离屏 1。再打开总览显示离屏标题占位，卡片保持在视口外的正确位置；Enter 可重新定位到原窗口，随后总览再次显示应用画面。
- 总览显示预览时关闭 Source，卡片/画面移除为 0/0，确认禁用，会话暂停，恢复日志为空。发现 hide 先于 destroy 时暂停地图可能留旧卡片，现已补充暂停期间的身份/销毁清理和回归检查；保留仍存活隐藏窗口的世界位置，不误作关闭。
- 使用最终构建复验：正常 Esc 后显示“总览已关闭；可再次切换导航”；再次打开可见 Source 帧 651，单独关闭 Source 后为 0/0，Esc 回主界面显示窗口 0、无旧卡片，最终恢复日志 Entries 为空。没有只靠模型检查宣称两个界面问题修复。
