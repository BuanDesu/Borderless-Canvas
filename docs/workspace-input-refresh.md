# 工作区跳转与导航操作更新

2026-10-24。按用户反馈统一工作区镜头、简化触控和导航入口，并增加六项键位设置。

## 工作区与焦点

关闭总览会把前台交还给先前应用。旧逻辑在把该应用移到离屏位置后，又把这次前台变化当作用户激活离屏窗口，覆盖了保存的工作区坐标。回归先用旧路径复现，再验证工作区交接记录当前前台状态，不触发这次自动找回；后续真正切换到另一离屏窗口仍保留找回行为。

工作区定位复用 Ctrl+滚轮的 150ms 平滑镜头，逐帧移动相机，保留窗口世界坐标和尺寸；终点直接采用保存的精确坐标。工作区移动不要求激活某个旧窗口。连续改选从当前帧开始，Backspace 返回整次移动的起点；关闭动画或系统动画时直接定位。新的导航、总览或暂停会取消旧过渡。

## 触控与提示

- 默认 Ctrl+Alt+V 开启/关闭触控导航；Esc、工具条退出、打开总览/面板、暂停或系统边界也会退出。
- 模式只接管两轴滚动消息；两指纵横滚动移动画布，Ctrl+滚动仍累计整格轮选。关闭某轴手势后，该轴输入交回应用。
- 移除全屏透明接触层、鼠标/单指按住拖动画布和失焦即退出。应用单击、双击、按住拖动以及输入保持原用途，不转发或重放点击。
- 菜单、任务栏和管理器不接管滚动。仅保留小型、不激活的工具条；工具条自身滚动由本地消息处理，其他窗口由钩子处理，避免重复累计。
- 手动导航模式和其原备用组合不再注册。普通视窗移动时显示约 900ms 的简短圆角提示；窗口不激活、鼠标穿透，闲置时隐藏。准星保持独立。

这里处理的是驱动提供的滚轮/水平滚轮消息；不将原始触屏接触自动解释为两指手势。具体触控板和远控仍需自然操作复验。

## 导航与键位设置

“更多 → 导航与键位设置”分为手势、快捷键两个子页。支持总览、准星、触控、便签、返回原点、上一视角六项配置；菜单及提示同步显示新组合。

全局组合仅接受 Ctrl+Alt（可加 Shift）配字母、数字、F1–F11（排除 F4）。Win 组合、Alt+Tab、普通编辑键、Delete、Escape、F12 等不在可用范围。默认 Home / Backspace 只在画布导航中生效，也可改成上述组合；它们不会注册为全局系统键。Tab 总览和 Esc 安全退出固定保留。

重复、非法或系统中已占用的组合显示错误，设置页保持打开。注册时先释放旧集合以支持组合互换，任一失败就撤销新集合并尝试恢复旧集合；不把部分成功写入设置。若恢复旧组合时也有外部冲突，会明确提示使用界面入口。设置写版本 3，兼容读取版本 1/2；旧手动组合字段仅为文件兼容保留，不再启用相应模式。读取旧版不自动重写。

## 验证边界

模型覆盖旧前台返回复现、工作区中间帧/精确终点/改选历史，以及重要系统键、重复和缺失组合的拒绝。隔离 worker 复用生产路由，验证两轴小增量、重复点击/拖动全部放行、菜单/暂停/Esc、准星交接及自定义上下文键；不安装钩子或注入系统输入。

原生检查只在未启用画布输入时临时注册自有测试组合，制造冲突并验证回滚、互换及旧组合释放，不发送组合键或激活桌面窗口。合成界面检查验证六项布局与错误不关闭；配置重启和版本兼容保留。真实四窗工作区往返、触控板点击、物理改键及不同设备组合仍需用户复验。源码仓库不包含真实工作区、输入轨迹、窗口标题、截图或本地诊断报告。
