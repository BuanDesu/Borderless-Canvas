# ADR 0003：隔离 UI 检查与实验

状态：采用。

原型曾将 UI 断言、基准、实验界面及正式程序编译在同一程序集。直接把 partial 夹具搬入引用 App 的程序集无法保持其私有访问；暴露全部控件字段或使用反射将增加耦合。

采用源链接 UI 宿主：App.Checks 直接编译唯一的生产界面文件及测试目录中的私有 partial 夹具，使用独立入口与程序集。实验工具 Lab 则引用正式 App，只有明确的 friend 访问，不形成生产到工具的反向引用。生产 App/Presentation 的实际编译清单受守卫检查。

可移植的交互/启动/模式状态首先进入 Application，并由默认 CI 检查。UI CI 检查控件连接；真实桌面和物理设备仍是另一层。源链接宿主不是生产 EXE 的逐字节替代，包验证额外启动实际 App 的有界运行时健康命令，并让临时宿主加载包内生产依赖与真正的 Recovery EXE。临时宿主只在本地忽略目录存在，不分发到 ZIP。

保留原生与兼容总览、输入线程、恢复所有权和安全暂停协议。本决定不授权改变用户手势或删除恢复保护。
