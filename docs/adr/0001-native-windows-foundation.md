# ADR 0001：Windows 原生基础项目

日期：2026-10-17。状态：采用，后续渲染方案允许调整。

## 背景

当前范围是连续二维窗口平移与空间总览，实际应用保持原生比例。工作区此前只有两份调研/需求文档；本机可用 .NET SDK 10.0.401 及 Windows Desktop 引用包。

## 决定

- C# 与 .NET 10，WinForms 承载桌面壳、托盘和原生 HWND 宿主。
- 通过 Win32 管理真实窗口，通过独立适配器接入 DWM 预览。
- 几何与导航放在不依赖 Windows 的类库，平台接管功能逐步接入。
- M0 不依赖外部 NuGet 包，使用可执行模型检查；需要测试框架时再单独决策。
- 当前不使用 WSL，不替换 DWM，不通过浏览器重建第三方应用，不做应用内容缩放。

## 原因与后果

当前工作的难点是窗口生命周期、准入、移动、恢复和空间坐标，不是复杂 UI。WinForms 可以直接提供 HWND 与消息循环，减少基础设施投入；不把 UI 框架当成整个桌面窗口的合成器。

运行源码需要 .NET 10 SDK，运行框架依赖包需要相应的 Windows Desktop Runtime。发布是否自包含、安装器、签名、自动更新均留到 M4。首个验证环境为 Windows 11 x64；没有因此声明对所有 Windows 版本或架构完成兼容测试。

Win32 功能增长后可以引入生成式 P/Invoke 或图形库，但不提前引入。若 WinForms 不适合后续高性能覆盖层，可替换 App/图形适配器，保留 Core 和 Application。

## 尚未解决

离屏窗口策略、混合 DPI、多屏视口模型、全局双鼠标键手势冲突和看护进程均需原型实测。本记录不将它们当作已验证能力。
