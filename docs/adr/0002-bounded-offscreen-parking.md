# ADR 0002：原型采用有界离屏停放，保留世界位置

日期：2026-10-17。状态：原型方案已决定；多屏接管仍待兼容验证。

## 问题与决定

Win32 的整数坐标不能直接代表任意远的世界位置。窗口离开当前视口后，采用与世界坐标独立的有界物理停放位置；进入视口时恢复 `P = W - C + WorkArea.Position` 的正确投影。世界矩形始终保留，不把停放矩形写回世界模型。可见窗口保持原生尺寸与相对位置，不隐藏、不最小化、不通过虚拟桌面切页组织空间。

停放选择所有显示器外的左、右、上、下候选区域，保留 64 像素间距。原型使用 ±30000 的保守原生坐标预算，尺寸也不超过 30000；这是本程序的试用范围，不代表 Win32 或所有应用的统一极限。没有安全位置或原生尺寸不匹配时拒绝操作，保留恢复能力。世界可远到 `1e20` 等有限 double 值，但浮点精度仍有限。

原型先开放单显示器管理。规划器会检查全部显示器，并拒绝部分可见窗口泄漏到邻屏；不能因此声明多屏画布已经可用。硬件实测为单屏 2560×1440、144 DPI（150%）。

## 对照实验

| 项目 | 有界停放 | 空窗口区域裁剪 |
| --- | --- | --- |
| 修改状态 | 位置；保持尺寸、visible、普通显示状态、层级与焦点 | 改变原有窗口区域，即使 visible flag 仍为 true |
| 原生验证 | 440×310 停到 `(-504,0)–(-64,310)`，不相交任何实际显示器；正常恢复原矩形 | 保存/恢复非矩形区域、NULLREGION 转换均通过本进程测试 |
| 透明测试窗口 240ms 计数 | timer +8 / paint +8 | timer +7 / paint +7 |
| 真正不透明源窗口的 DWM 图像 | 已观察到冻结旧帧 | 已观察到空白 |
| 独立异常恢复 | T04 原始 placement 和实例标记适用 | 当前持久日志没有任意 region 数据；不进入生产路径 |

透明窗口的 paint 计数只能说明消息继续处理，不能说明桌面合成图像刷新。因此另外建立可视 Probe 程序，用真实 DWM 缩略图和不透明源窗口观察像素。原生 DWM 查询得到源表面 422×301，而外部窗口为 440×310，说明预览应使用 DWM 自身尺寸做比例适配，不能把外部边框尺寸当作缩略图像素尺寸。

Computer Use 实测：停放后，源计数已到 383，预览仍停在 FRAME 314；裁剪时源计数 575，预览区域为空；移回并清除裁剪后，预览恢复至 FRAME 640，后续到 FRAME 1326，文本框成功接收“BFW 原生输入验证通过”。最后通过控制器关闭实验，确认两扇 Probe 窗口退出。未操作用户应用或修改系统设置。

可复现实验：构建整个解决方案后，运行 `tests/BorderlessFlatWindow.Probe/bin/Release/net10.0-windows/BorderlessFlatWindow.Probe.exe`。控制器提供停放、裁剪、原位恢复、所属弹窗和 DWM 预览。只有本程序创建的 Source 会被其控制器操作；关闭实验先尝试恢复。Probe 是测试工具，尚不是可试用画布原型。

## 预览、任务栏与弹窗

离屏时计时器和应用逻辑可继续，DWM 图像可能冻结或不可用。总览必须保留标题/图标卡片和正确世界位置，允许用过时图像作带说明的缓存预览；不能依赖实时画面，也不能向缩略图注入编辑输入。

真实任务栏 hover 预览未完成视觉验收：当前 Windows automation surface 没有返回可操作的任务栏窗口。已经验证的是本程序 DWM 预览的 API 与像素行为，不能把它当作 Explorer 任务栏预览已验证。程序不改变窗口的任务栏资格；任务栏激活跟随将在 T06 验证，任务栏具体图像行为留在兼容矩阵。

所属弹窗实验显示，owner 停在屏幕外后，新 popup 仍可在屏幕内出现，未可靠跟随 owner 的停放矩形。原型遇到与受管理窗口关联的普通弹窗时，应先暂停并恢复整个会话，保持模态交互可操作；不能仅排除 popup 然后继续把 owner 留在远处。完整关联移动、全屏、置顶、其他虚拟桌面和多屏行为后续验证。

权限方面，移动入口只接受活跃恢复会话的 armed ID，重新核验身份和实例标记；未知 ID、原生尺寸变化、最小化、最大化、置顶或非顶层状态会拒绝。UIPI 拒绝标记/身份查询时不授予移动权限；本次没有用管理员应用做兼容实测。

## 证据与后续

81/81 模型检查、6/6 文件检查、33/33 原生检查通过；新增 8 项规划模型检查和 7 项原生对照实验。原生结果在 ignored `artifacts/offscreen-probe.json`，视觉观察摘要在 ignored `artifacts/offscreen-visual-probe.json`；相关窗口截图由 Computer Use 在会话内展示，未导出或上传。真实多屏漏出只做了规划模型数据验证，实际硬件仅一屏。

T06 必须把停放状态、预期位置回调与真实世界模型协调：停放的 native 坐标不能污染世界位置；逐窗请求不视作跨进程原子事务，失败要暂停恢复。显示拓扑/DPI 改变时应退出当前管理并恢复，再重新建立基线。
