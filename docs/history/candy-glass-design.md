# 糖果色玻璃界面

> 历史记录：保留当时的实现与验证过程。当前规则以[架构](../architecture.md)、[检查分层](../testing.md)和[验收清单](../release-v1-readiness.md)为准。

2026-10-19。初版糖果玻璃已集成；本轮按后续反馈增加播放器外壳、CRT 工作区、统一的通透总览和独立托盘图标。

本文记录糖果材质与交互实现。用户随后已确认桌面右击、两种双键顺序及托盘图标正常；新一轮的竖向面板、独立总览过渡、字体布局和壁纸配色以[后续设计](console-and-wallpaper.md)为准。

## 设计依据

参考 Microsoft 的 [Acrylic 材质规范](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)和[命令栏规范](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/command-bar)：材质表达层级，常用命令直接可达，次要命令通过更多菜单展开。颜色、曲面和标记由项目自行绘制，没有引入第三方图片或字体资源。

采用高饱和的粉紫—冰蓝渐变外壳，参考随身 MP4 播放器的凹入式显示面、扬声器孔和圆润边框。胶囊、爱心与糖果以原创低像素图案点缀，不作为按钮，避免装饰与功能混淆。内容使用深色文字、彩色玻璃叠层、高光、投影和按压位移；取消像素网格和大号技术口号。

## 信息层级

- 主命令栏仅显示“开始画布 / 暂停并恢复”（按状态二选一）、“空间总览”和“更多”。
- 更多菜单按视角、窗口、设置、恢复组织。返回原点、上一视角、适配地图和手动导航位于视角子菜单，已有快捷键继续有效。
- 未开始时显示窗口选择；运行后自动收起。需要手动加入窗口时，通过“更多 → 管理窗口”展开，保留默认自动接入开关。
- 相机坐标、离屏数量和输入注册状态移到运行信息或悬停提示。发生接管/恢复错误时，主界面仍显示原因，不因精简而隐藏失败。
- 总览上方只显示空间地图，搜索、选中窗口提示、选项和关闭全部合入下方工作区底座。整页使用同一内存模糊背景，没有分隔的上下白色带。默认不画参考视口框，可在选项中开启；窗口标题、比例、相对位置和选择语义保持。
- 工作区为接近方形的 CRT 正视图，含圆角机壳、凹入屏幕、指示灯与底座；屏幕按该工作区的真实相机坐标绘制窗口位置。缩略布局不伪造应用截图。数量较少时居中，溢出时横向滚动；名称保留在底座下方，坐标在悬停提示中。
- 工作区保存、管理和右键重命名/删除仍可使用。下方占比随屏高约为 1/5；紧凑窗口保留 210px 的可读下限，避免屏幕与搜索互相挤压。

总览卡片颜色由稳定窗口 ID 决定，切换焦点不换色；焦点通过轮廓和阴影强化。图形使用原生路径及像素矩形绘制。主窗口采用应用内玻璃叠层；总览是打开时的桌面模糊快照，着色遮罩从 100/255 降至 28/255。它不是实时合成器透明材质。DWM 预览仍是真实窗口画面，失败时使用标题卡片。进入总览时关闭主界面悬停提示，防止旧提示盖在地图上。

托盘、标题栏和 EXE 使用同一原创显示器图标。ICO 包含 16、20、24、32、48、64、128、256px 八种尺寸，托盘加载小图标并持有资源直到释放；`scripts/generate-brand-icon.ps1` 可重建。系统可能将图标放入任务栏的隐藏图标区域，软件不修改用户的系统托盘偏好。

## 桌面右击

双键拖动仍需暂存第一键，避免产生误点击。新增单独右击判定：从桌面开始、未参与双键、未越过移动阈值/应用边界、没有滚轮操作，且释放时仍是同一桌面目标，才将一个平衡的右键按下/释放交回 Windows。实现不移动指针、不生成键盘输入；自己的回放带标记，不再次进入钩子处理。失败不循环重试，而是暂停自动导航，允许下一次直接右击。中途退出、总览、故障和新按钮操作均不能触发迟到点击；菜单期间自动导航与桌面 Tab 暂停。

依据：[SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)、[低级鼠标输入标记](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)、[GUI 菜单状态](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-guithreadinfo)。此回放仅用于应用本身的桌面手势仲裁，验收没有使用自建输入注入脚本。

## 验证

- 202 项模型、15 项文件存储、48 项原生检查通过，构建 0 警告、0 错误。新增检查覆盖单独右击只触发一次、两种双键顺序及松开顺序、右拖动/越界和滚轮/取消/退出不回放；托盘 smoke 检查确认资源句柄、尺寸和可见像素。
- 使用合成窗口与工作区渲染常规、800×560 紧凑窗口、总览、搜索和诊断页面，实际查看图像修正搜索栏裁切与工作区滚动条占位。
- 前一版本的用户人工验收已全部通过：自动输入切换、Tab 总览、Ctrl+滚轮轮选、工作区保存/取消/跳转、托盘返回及双屏平移。具体显示器型号、排列和 DPI 未采集；不推定所有多屏组合均已通过。
- 该阶段的实际 GUI 仅接管自有 Probe Source，确认主界面切换、下方搜索过滤、取消总览、真实预览与统一模糊背景。结束时关闭自有测试进程，独立恢复跳过已关闭目标，剩余记录为零。之后用户已在 `5842b18` 包确认：桌面右击及关闭菜单后滚轮正常；双键松开不误弹菜单，Backspace 返回整段起点；托盘原创图标可见且双击返回。真实桌面图像及本地数据不纳入提交。

更广应用、混合 DPI、性能和正式发布范围仍按 T11–T13 跟踪。
