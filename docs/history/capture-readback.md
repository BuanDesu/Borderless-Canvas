# 总览采集核验与读回测量

> 历史记录：保留当时的实现与验证过程。当前规则以[架构](../architecture.md)、[检查分层](../testing.md)和[验收清单](../release-v1-readiness.md)为准。

## 截图前后分别核验

保留式总览原先在截取整个桌面后才开始两次焦点核验。如果遮挡窗口在截图后移开，两次检查都可能通过，而旧截图中仍有遮挡内容。当前把入口整理为“前置资格核验 → 桌面读回 → 克隆焦点区域 → 后置核验”。前置拒绝后，即使读回期间遮挡已移开，也不接受该焦点图像；后置身份、位置或遮挡变化同样丢弃裁剪，地图仍可打开。

`OverviewBackdropCapture` 明确持有背景及裁剪；背景用于上传后释放，焦点图像只转移一次。异常会释放已创建的两类位图。没有把两次观察描述为原子截图保证，也没有放宽分层源、未知边界、身份或遮挡保护。

新增合成像素回归覆盖检查顺序、截图后移开遮挡、期间改变源、读回失败、越界区域、一次所有权转移和后置异常释放；测试不读取真实桌面。

## 入口阶段计时

`--motion-metrics` 继续只输出匿名数值及固定枚举；默认不写此文件。保留 `CaptureMs` 总段，并拆出：

| 字段 | 含义 |
| --- | --- |
| `RawCaptureMs` | 屏幕读回，含该后端的分配与像素转换 |
| `FocusEligibilityMs` | 读回前的焦点资格核验 |
| `FocusCloneMs` | 内存中克隆焦点区域 |
| `FocusRecheckMs` | 克隆后的资格核验 |
| `UploadMs` | 背景上传到 WPF 纹理 |
| `BackdropCaptured` | 是否取得背景，避免将失败的零耗时当成速度提升 |
| `ReadbackBackend` | 固定值 Graphics / DirectDib / None |
| `FocusWasForeground` | 核验前焦点源是否真的位于前台，无句柄或应用名 |

以上是 `CaptureMs` 内的分段，不能再与总段相加；`HostShowMs` 也包含准备、布局和预览同步等子段。首个合成回调仍不等于 GPU 或屏幕实际呈现。

可选计时启用时才额外读取重叠窗口的匿名样式分类，汇总为 `CropOcclusionKinds`：1=本管理进程、2=源进程、4=分层、8=透明输入样式、16=工具窗、32=置顶；按位或，不输出窗口数量、名称、类名、身份或路径。普通资格查询不做这些额外分类。透明输入样式并不代表视觉完全透明，因此分类不参与放宽判定。

一轮直接入口实测中，源确实在前台，仍报告遮挡，分类为 60（分层、透明输入、工具、置顶），不含管理进程或源进程。该环境存在外部叠加层；不因自动化测量而忽略它。当前自动化的真实焦点缩放验证继续标记为未完成。

## DIB 读回实验

默认保留原 Graphics.CopyFromScreen 路径。开发者可用 `--direct-readback` 显式启用实验后端：从桌面 DC 向自有自顶向下 DIB 进行 SRCCOPY，调用 GdiFlush 后把 RGB 像素转换成独立、不透明的预乘 ARGB 位图。原生 DIB、DC 在返回前释放；失败回退原路径。没有新依赖、后台抓屏或磁盘图像。

[CreateDIBSection 文档](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createdibsection)要求直接访问像素前同步 GDI 操作，并说明 DeleteObject 的内存所有权；[BitBlt 文档](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-bitblt)说明格式转换与设备限制。实验保持与原路径相同的 SRCCOPY，不以新选项扩展被保护内容的捕获。

合成原生基准使用真实内存 HBITMAP 作为源，原路径的 Graphics/HDC 目标写入作为对照；不是用 Graphics.GetHdc 的临时写桥当作已有图像的读源。最初错误夹具产生的透明/黑色结果已排除，不能据此声称原读回路径存在 alpha 故障。修正后两条路径的颜色及不透明 alpha 均通过。

三种尺寸、每种后端各五次，交替先后顺序，共 30 个内存 DC 样本；核对偏移、尺寸、方向、颜色、alpha、返回位图独立性、无效输入及单次捕获的 GDI 资源数量无增长。一轮开发均值（ms）：

| 尺寸 | Graphics/HDC | Direct DIB |
| --- | ---: | ---: |
| 1920×1080 | 6.23 | 3.93 |
| 3440×1440 | 11.44 | 9.62 |
| 960×720 | 1.82 | 1.23 |

这些是合成内存拷贝，不包含真实屏幕的 GPU 读回同步。独立自有 Probe 的原路径样本读回约 36.9/26.3ms，DIB 约 40.2/26.8ms；直接入口、冷/热状态及采样顺序不同，不是严格 A/B，未显示足够的真实读回收益，因此实验后端不设为默认。后续继续研究实际呈现和采集同步，不能用内存基准代替真实响应性验收。

## 回归与恢复边界

完整模型、存储、原生检查及三尺寸场景保留；原生遮挡夹具还核对匿名分类不改变拒绝结果。受控真实 Source 验证普通入口、重开、Tab 返回及暂停恢复。一次独立开发实例在接管唯一自有 Source 后强制结束，独立恢复入口验证原始位置和显示状态，Remaining=0，随后 inspect 为零。该证据不替代常用应用、混合 DPI、任务栏及长期资源矩阵。

原始时序、运行日志和恢复数据仅保存在本地；仓库记录上述匿名结论。T11/T12 及总览真实流畅度继续开放。
