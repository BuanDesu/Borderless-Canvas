# 功能集成与验证

当前设计以[架构](../architecture.md)、[检查分层](../testing.md)和[验收清单](../release-v1-readiness.md)为准。

窗口准入、显示坐标、只读空间地图、恢复日志、有界离屏停放、原生画布、全局导航、空间总览、窗口预览和位置持久化按依赖顺序集成。每项集成核对目标构建的检查结果与文件树，并保留功能提交及合并拓扑。

触控板接收层使用真实命中结果，画布支持双轴平移。仅延长透明期未能解决桌面单次右键；随后采用桌面成对交接、退出状态顺序及匿名诊断，并通过本机实体复验。该结果仅覆盖已测设备，不代替多设备、混合 DPI 或长期资源验收。操作与边界见[触控板验证](../touch-context-handoff.md)。
