## 操作与外观

- 桌面空白处 Tab / Shift+Tab 进入总览，总览内同样按键返回；Esc 保留。方向键按空间选窗，Ctrl+Tab / Ctrl+Shift+Tab 轮选，Enter 定位。工作区命名等模态对话框仍使用普通 Tab 焦点遍历。
- 应用中的操作按钮使用 `ChromeButton` 完整绘制，保留 WinForms Button 的键盘、可访问性和对话框语义，不调用系统默认的悬停/焦点边框绘制。键盘焦点使用圆角强调线；按钮的原生裁剪区域匹配圆角轮廓。透明按钮的绘制缓冲主动初始化，避免残留底层控件文字。
- 底部方向键、返回和更多键使用原创 `keycap-square.svg`；开始/暂停、总览使用 `keycap-round.svg`。嵌入的受限 SVG 渲染器只处理这些自有素材中的圆角矩形、椭圆和两端渐变，按当前糖果配色着色，不加载外部内容。标签容器、内容页和原生列表也采用圆角裁剪。
- 私有加载 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的 12px proportional 简中版本，覆盖简体中文与英文。字体通过 GDI 与 GDI+ 内存注册使用，不安装到系统；默认文字按 12px 基准绘制并跟随 DPI。来源、版本、校验值和字体及上游许可证见应用资产中的 `Licenses/FusionPixel/NOTICE.md`。

## 预览与合成

地图不再因来源离屏、卡片重叠或小于 110px 主动关闭预览，也没有默认 16 个窗口的上限。每个存在有效来源和可绘像素的匹配窗口都尝试使用 DWM。极小到不足可绘像素、来源退出/不允许捕获、注册失败或用户关闭预览时仍保留标题和空间位置。DWM 无法保证离屏应用继续重绘，预览可以是最后一帧；本轮恢复可用内容，不把“注册成功”等同于实时刷新。

CRT 工作区的屏幕使用对应相机视窗的实际窗口内容。每个窗口按世界位置投影，超出视窗的部分通过 DWM 来源矩形裁剪；显示器之间的空隙和任务栏区域不绘窗口内容。每个可见卡片中的每个窗口切片单独持有关系，横向滚出区域后释放。壁纸按当前多屏布局在后台生成小尺寸内存预览，所有工作区共用固定桌面背景；不使用抽象色块代替应用画面，不写入壁纸路径或像素。

注册前完整核验 HWND、PID、进程启动时间、可见性、cloak 和当前桌面，再设置独立随机属性，并在注册后复核。后续更新用随机属性与 PID 检查生命周期，避免每帧重复 COM 查询；源窗口销毁后属性失效，不能继承到复用的 HWND。来源尺寸在普通同步时读取，动画只复用已核验关系。位置、裁剪和透明度没有变化时不再跨原生边界更新；失败隔离和 F5 显式重试保留。

进入前隐藏可见面板并提交本进程的 DWM 更新，再取背景，避免旧面板进入过渡截图；只增量复核受管理窗口，不在每次进出时重新枚举无关桌面窗口。预热地图和工作区预览并缓存最终界面。约 220ms 的缩小过渡由覆盖层与已注册的 DWM 关系完成，地图和工作区的子窗口始终保留，不在结束时隐藏/显示并重新布局；当前/最后焦点的屏内窗口缩小到其地图位置，其余预览渐入。离屏焦点仍显示地图预览，只不从不可见的物理矩形开始缩小。退出约 120ms 同时淡出宿主与预览，再执行定位或恢复焦点。遵循 Windows 客户区动画开关，也可在外观菜单关闭。

画面、桌面模糊图及壁纸预览只在进程内存存在。仓库和试用包仅包含源码、原创矢量素材、授权字体和文档，不包含本机截图、应用标题清单、恢复记录或壁纸文件。

## 验证与边界

- Release 构建零警告/错误；217 项模型、15 项文件存储、51 项原生检查通过。新增验证覆盖 48 个无默认上限的模型预览、原生 24 个停放/重复来源关系、来源裁剪与重置、透明度变化、负/远坐标、视窗边缘、多屏间隙、动画不重新查询尺寸或注册、动画回调重入隔离，以及空闲重复同步不发送更新。
- UI 合成渲染覆盖竖向面板、诊断三个子页、冷暖配色、紧凑与大字号总览、过渡中间帧。原生字形查询检查简中与英文字符确实来自已加载的字体。
- 界面复核模式仅接管自有 Probe Source，已观察地图画面与 CRT 原点卡片中的真实应用内容，Tab 退出后返回面板。对比合成书签 `(0,720)` 与 `(300,0)`，分别看到空视窗和边缘裁剪的 Source，与原点的完整 Source 内容不同；悬停更多键、标签键盘焦点和三个诊断标题已查看。测试结束独立恢复验证原始位置和显示状态，剩余记录为零。桌面工具不能可靠操作嵌套模态输入，因此新书签由独立的本地合成文件提供，不把该步骤作为模态输入验收。
- 自动化的静态截图与 HRESULT 检查不能证明进出过渡没有可感知闪烁、所有设备都流畅或所有离屏应用都会刷新。最终包仍需在用户的实际桌面复验过渡、悬停/焦点边缘和多窗口工作区内容；广泛兼容与大规模性能矩阵仍属于 T11–T12。

接口依据：[DWM_THUMBNAIL_PROPERTIES](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ns-dwmapi-dwm_thumbnail_properties)、[DWM 缩略图概述](https://learn.microsoft.com/en-us/windows/win32/dwm/thumbnail-ovw)、[DwmFlush 的进程更新边界](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmflush)。
