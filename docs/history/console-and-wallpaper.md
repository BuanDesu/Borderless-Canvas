## 竖向游戏机面板

主界面改为约 432×700 逻辑像素的竖向浮动面板，随 DPI 缩放并限制在目标显示器的工作区内。初次在主屏右下角、任务栏上方出现；从托盘打开时使用光标所在显示器。它不参与画布平移，也不占独立任务栏按钮。点击其他应用后收起，右上角 × 同样收起；托盘双击或菜单可重新打开，托盘退出命令仍先恢复窗口。

底部以掌机按键组织操作：方向键平移、中心键返回原点、返回键回到上一视角，圆形按键用于开始/暂停与空间总览。更多菜单保留窗口、导航设置、恢复和外观等次要命令。诊断与恢复页的操作也放在下方。窗口列表在未开始时显示，运行后收起，需要时通过更多菜单展开。

诊断标签根据字体测量宽度，必要时换行；说明文字按可用宽度计算高度。工作区名称按实际字体留出独立区域，机壳、底座与标题不互相覆盖。验证包含当前 150% DPI 的竖向面板、三个诊断子页，以及总览的大字号渲染；不推定所有 DPI 组合均已验收。

## 总览过渡

总览使用独立的顶层窗口，不再将管理器 HWND 拉伸到整屏。打开前保留内存桌面快照及模糊图，预合成最终界面；进入的约 240ms 内只由一个缓冲表面绘制背景和界面渐变，避免多个子 HWND 逐块刷新。当前或最后一个受管理的焦点窗口若仍有效、完整位于目标屏幕内，则使用经过身份核验的 DWM 预览，从原屏幕矩形平滑缩小到地图中的位置。只动画预览，不移动或缩放真实应用窗口。

动画结束后沿用相同预览资源进入正常地图，释放临时位图。离屏、跨屏、关闭、预览失败或无焦点目标时，使用标题视图/短过渡降级，不伪造实时内容。Esc 可立即取消；其他导航输入可跳过过渡，迅速进入可交互地图。遵循 Windows 的客户区动画开关，也可在“更多 → 外观 → 总览缩放动画”关闭。当前只实现进入过渡，退出直接定位或取消。

动画和总览图像只在内存中存在，不写日志或上传。性能仍受设备、桌面尺寸与 DWM 是否提供画面影响，未承诺固定帧率或离屏持续刷新。

## 壁纸配色

使用 Windows 的 `IDesktopWallpaper` 读取面板所在显示器的当前壁纸与布局。在图像上按 5×5 点位取色，映射考虑居中、平铺、拉伸、适应、填充和跨屏模式。按主导色相选取糖果色，并生成相邻/搭配的强调色；纸面由强调色与白色混合，文字保持深色，按钮按黑白对比选择前景色。取色不用桌面截图，因此应用窗口和通知不会污染颜色。

读取和解码在独立 STA 后台线程进行；壁纸设置变化时重新采样，总览打开期间延后应用新颜色。无图片的纯色背景也可参与取色。中性、近黑、无法解码、超过图像尺寸限制、远程路径或接口不可用时退回默认糖果配色；不下载资源、不改壁纸、不保存壁纸路径或像素。

“更多 → 外观”可以关闭跟随壁纸、手动重新采样及关闭动画。外观选项与导航设置目前均只在当前进程内生效；托盘品牌图标保持固定，方便识别。

依据：[Windows 壁纸接口](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nn-shobjidl_core-idesktopwallpaper)、[GetWallpaper 的多屏与幻灯片语义](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-idesktopwallpaper-getwallpaper)、[DWM 缩略图](https://learn.microsoft.com/en-us/windows/win32/dwm/thumbnail-ovw)。

## 验证边界

配色模型覆盖主色相、纯亮色、中性回退、枚举顺序、强调色对比、壁纸裁切与负坐标跨屏；过渡几何覆盖端点、时间夹取及不超调。原生检查只读取当前壁纸的监视器元数据并验证未改变前台，不输出路径、不改变系统壁纸。合成画面检查覆盖竖向各页、工作区名称、大字号与过渡中间帧。

本轮 210 项模型、15 项文件存储、50 项 Windows 原生检查通过，Release 构建 0 警告、0 错误。已查看冷暖两套合成配色和各子页；在界面复核模式只选择自有 Probe Source，验证开始、方向键、返回、独立总览真实预览、完整“原点”名称与取消。结束后独立恢复验证原始 placement/show state，剩余记录为零。复核模式保留的任务栏入口与可见性不作为正式弹窗收起行为已通过的证据。

最终包仍需用户复验 Tab 进入过渡的主观流畅度、面板位置/外部收起、托盘返回及配色协调程度。真实多设备与性能矩阵仍留在 T11–T13。

开发复核可使用 `--review-panel`，临时保留主面板/总览的任务栏入口并禁止面板自动收起，便于有窗口筛选限制的桌面工具选择目标。该参数不改变配色、布局、预览、导航或恢复逻辑；正常启动不启用。
