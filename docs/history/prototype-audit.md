## 保留的范围与风险

当前开放 DPI 已知的单显示器普通窗口；最大化/全屏/置顶等状态需要先退出，关联弹窗或失败会暂停恢复。离屏图像可能停帧，用户只确认任务栏预览可显示，未证明持续实时更新。

更广第三方应用、管理员应用、输入法、多屏/混合 DPI、拔插/休眠、性能矩阵和 UI 长时间阻塞的整体压力验收仍未完成。完整导航键自由重绑定、区域平铺/撤销、托盘、许可证、签名、安装器和自动更新仍属于首版/发布后续；不以本次原型交付宣称这些功能完成。

标签跨重启保存，世界窗口布局和导航设置目前仅本次进程有效。逻辑世界没有固定页数/槽位，但受有限数值精度、存储和系统资源限制。以上边界已在指南中说明，保留最初连续二维空间、原生比例操作和正确相对位置总览的核心语义。
