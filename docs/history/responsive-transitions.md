# 可中断总览与页面过渡

> 历史记录：保留当时的实现与验证过程。当前规则以[架构](../architecture.md)、[检查分层](../testing.md)和[验收清单](../release-v1-readiness.md)为准。

跟踪 [Issue #39](https://github.com/BuanDesu/Borderless-Flat-Window/issues/39)。用户认为 #37 的面板方向基本合适，但总览仍有等待和卡顿，Tab 不能快速往返，右上角关闭键偏小，圆角裁切文字，主面板换页缺少过渡。本轮保留视觉方向，调整这些具体行为。

## 输入与总览生命周期

- Tab / Shift+Tab 在进入或取消返回途中，直接把当前 0–1 位置作为新起点反向；不强行完成旧动画，不排队播放完整动画。时长按剩余距离计算，进入上限 220ms、返回上限 180ms。
- 进入前的请求仍保留奇偶语义；准备期间到达的切换请求不会丢失。原生键盘钩子只在已请求的准备阶段或当前总览 HWND 位于前台时捕获普通 Tab。Ctrl+Tab、应用内 Tab 和模态编辑中的 Tab 保留原有用途。
- 过渡期间继续输入心跳并消费总览切换和故障事件。导航保持暂停；关闭、故障和暂停仍可最终清理资源。
- 总览停稳后保留隐藏的合成宿主和纹理；取消时复用它们。只有搜索、选择、地图几何、工作区内容或外观改变才重新生成目标界面。完全关闭后释放，下一次独立打开仍需准备背景与界面。

## 合成与预览

屏内焦点窗口在身份、位置和遮挡检查通过时，使用短期内存图像，通过同一 WPF 合成层里的 ScaleTransform / TranslateTransform 缩小到地图。动画过程中更新已有 RenderTransform，避免反复布局；依据 [WPF 布局性能建议](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-layout-and-design)。过渡结束后切回原有 DWM 预览，地图与工作区继续显示真实窗口内容。

图像来自已存在的桌面内存快照。截取前后均核验 HWND、PID、创建时间、可见状态、非最小化、未 cloak 和物理边界；拒绝 layered 源，以及上方存在相交窗口、无法核验或枚举超限的情况。[EnumWindows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumwindows) 回调有数量上限，不读取其他窗口的标题。未满足条件则保留原生 DWM 移动预览，不把被遮挡的桌面图像冒充窗口内容。

停留后取消返回时，尝试从本程序地图中的当前 DWM 内容刷新短期图片，并再次核验地图区域无遮挡。该图像在放大时可能暂时较软；验证失败时继续用原生预览。动画途中反向复用同一图片，不再次抓取。确认另一个窗口或工作区不播放回到旧焦点的放大。

生产背景绘制按子控件实际矩形复制对应区域，避免每个透明子控件重复绘制整屏背景。窗口实际尺寸、世界坐标和恢复记录不因这些视觉过渡改变。

## 面板规则

- 关闭键为 48×48 逻辑像素，随 DPI 缩放；X 用居中的矢量线条绘制，与品牌显示区共用垂直中心。
- 圆角保留在外壳和装饰表面。移除 TabPage、标签宿主和原生列表的 Region 裁切；页面内部留出上 12、左右与下 8 逻辑像素，避免切掉标题和表头。
- 主标签和设备诊断子标签加入约 140ms 的合成淡入。先呈现旧页覆盖图，再切换原生页面和上传新图，避免中间露出空白页面。
- 过渡过程中新的页面请求从当前混合画面继续；准备期只保留最新目标。点击当前页可取消尚未提交的切换。调整大小、隐藏、销毁和异常均停止逐帧订阅；系统关闭客户区动画或无硬件渲染能力时直接切换。
- 页面快照仅包括本程序自身控件；取色更新在页面过渡完成后应用，避免中途换色。

## 验证与边界

模型检查覆盖连续反向、快速交替请求的奇偶结果、端点和非法参数，以及总览/准备/模态/应用输入路由。纯合成 `--motion-check` 覆盖 1920×1080 和 3440×1440：图片缩放、两次中途反向、正确终点、停止与重复释放；不抓取桌面。

原生检查覆盖截图资格的身份、隐藏、移动、透明样式与遮挡，以及原有预览和恢复行为。夹具等待自身窗口稳定准入；首次 DWM 注册允许最多两秒初始化，最终的资源数量、状态和释放断言不变。新增 `--overview-only` 可隔离运行总览原生检查，默认全量入口不变。

本机真实自有 Probe 已检查主页面及诊断页面、文字上缘、Tab / Shift+Tab 返回和真实地图内容；该环境的截图资格检查检测到遮挡，实际走原生预览降级，不能把合成图片路径的纯色检查当成真实桌面流畅度验收。初次背景及界面准备仍有开销，屏幕分辨率、窗口覆盖关系、DPI 和系统负载会影响等待与呈现。回调间隔不等于 GPU 呈现帧率，快速物理连按和主观顺滑程度仍待用户复验。

此前完整回归出现过恢复日志原子替换的访问失败和夹具初始化超时；原始本地日志保留在忽略目录，不通过放宽恢复断言规避这些失败。最终检查及打包结果单独回填 Issue，不能据一次通过宣称已消除偶发问题。

桌面、壁纸和焦点图片只在内存使用并随宿主释放。可选 `--motion-metrics` 只增加场景复用、合成焦点与截图资格分类等数值，不记录标题、窗口身份、路径或像素。试用包和仓库不包含本地恢复日志、标签、截图或运行指标。
