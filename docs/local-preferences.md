# 本地设置与失败降级

导航手势、滚轮距离、六项导航键位、自动接入、壁纸取色和总览动画现在保存在 `%LOCALAPPDATA%\BorderlessFlatWindow\settings.json`。正常修改立即作用于本次会话并尝试保存；重启读取上次保存的选择。默认文件不存在时使用原有初始值，不在启动时自动写入默认配置。

这里只保存版本、操作选项和键位；不保存窗口身份、名称、布局、相机、已选窗口、壁纸路径/像素或输入内容。恢复与工作区仍分别使用原有文件。正常启动在设置、设备、事件监听和输入初始化就绪后自动开始，纳入全部可用普通窗口，便签独立；这会建立新会话，不恢复上次世界布局。设置首次读取失败或存在待恢复记录时不自动开始。手动暂停、独立恢复及系统切换后仍等待明确开始。

“更多 → 本地设置”可重新读取已保存设置、明确保存当前选择和查看存储状态。重新读取会替换未保存的本次选择；保存当前设置尝试重新取得写入权并以当前选择写入有效文件。损坏或未知版本文件不会因此被覆盖，需先修复/移走原文件后重试。配置写入失败时运行选择继续有效，界面提示“仅本次会话生效”，旧文件保留。

初次读取失败时自动接入保持关闭，其他项使用默认值；之后重新读取失败保留当前运行选择。一个实例持有写入租约，其他实例仍可读取已保存设置并在本次会话修改。外部编辑触发指纹冲突时停止隐式写入；可重新读取，或明确保存当前设置。没有文件监控轮询、后台上传或输入钩子内的文件操作。

## 文件与入口

托盘“设置”可直接进入同一导航设置弹窗，或打开取色与动画、本地设置菜单。编辑导航设置时暂停画布导航，保存/取消后恢复；行为与主面板入口一致，见[托盘说明](tray-control.md)。

JSON 写入版本 3，兼容读取版本 1/2 并补充新键位的默认值；读取旧版不重写文件，下次正常保存才更新。读取上限 64 KiB，拒绝重复/未知/缺失字段、非法类型、无效距离或组合，以及未来版本。旧手动组合字段只供文件兼容，不再注册。六项键位的允许范围、上下文和注册失败回滚见[导航更新](workspace-input-refresh.md)；不接受任意系统组合。

保存先写同目录唯一临时文件并刷盘，提交前再次比较来源指纹，再原子替换。失败保留旧文件并清理临时文件。租约防止协作写入，指纹检测普通外部编辑；它不是跨任意外部编辑器的原子比较交换协议。设置、工作区和恢复路径经规范化后不能相同。

独立验证或多个本地配置可显式运行：

```powershell
./BorderlessFlatWindow.App.exe --settings C:\path\settings.json --journal C:\path\recovery.json --bookmarks C:\path\bookmarks.json
```

修改保存的导航组合直接用于输入线程首次注册，启动时不先注册默认组合。注册冲突保留所选组合并明确提示，不静默换键、不自动进入导航。

## 验证范围

模型覆盖读写失败、只读实例、显式重试/重新读取、非法选择、初始损坏与后续运行选择的保留。文件检查覆盖重开、字段白名单、损坏/未知/重复/缺失/越界数据、租约、替换失败、外部编辑、大小限制及路径别名，进入默认 CI。

UI 检查直接使用实际复选框、菜单命令和导航设置应用函数保存，再重新构造管理器读取；核验外观/导航/接入绑定，保持未接管且无恢复日志。无效文件下的同一操作不覆盖原字节。原生输入检查验证初始组合直接注册、冲突可见、未激活且无输入入队。透明夹具无显式路径时只使用内存设置，不读取真实用户配置。

真实独立开发进程另从预置配置启动，观察自动接入关闭和默认配色；通过实际复选框/菜单打开自动接入及壁纸取色，文件对应字段更新，距离和备用组合保留。结束此实例并以相同独立路径启动新进程，界面选择与配色保留，设置哈希及修改时间证明启动没有重写；始终未接管窗口，独立恢复 inspect 为零。重复数据路径的 CLI 验证在存储打开前返回错误且没有创建对应数据/锁文件。两个开发实例均已结束，用户原试用实例保留；没有把这一范围外推为所有手势的自然操作验收。

紧凑错误布局曾复现地图高度不足而固定 48 像素留白触发绘制异常，现改为随较短边调整，上限仍为 48；核心投影的非法输入拒绝不变。新增空/有窗口的七种紧凑尺寸直接绘制回归，并检查合成错误面板的提示和底部命令可见。显式 UI smoke 模式在任何窗口创建前设置异常抛出，不等待框架异常对话框；正常运行不改变该策略，时机依据[微软说明](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.application.setunhandledexceptionmode?view=windowsdesktop-10.0)。

真实设备、广泛应用、六项键位的物理操作、GPU/长期资源及正式发布仍继续按 T11–T13 验收。原始本地设置、日志及桌面画面不提交仓库或试用包。
