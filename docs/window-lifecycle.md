# 事件同步与真实空间地图（T03）

2026-10-17：实现 WinEvent 增量同步和第四页“真实空间地图（只读）”。没有接管或移动用户窗口。恢复日志、离屏策略、真实平移和全局导航仍按后续任务推进。

## 数据流

1. 在有消息循环的 STA 线程安装 out-of-context WinEvent hooks，默认跳过本进程。回调只分类、入队并启动一次 40ms 批次调度，不在回调中查窗口或更新地图。
2. 监听创建、销毁、显示/隐藏、位置/尺寸、名称、状态、cloak/uncloak、前台和桌面切换提示。对象事件只接收 OBJID_WINDOW / CHILDID_SELF；读取端再次检查 GA_ROOT，防止子控件事件把目录扩展成控件树。
3. 初始启动、手动检查和明确的桌面切换提示做全量发现。普通事件只对相应 HWND 重新读取当前状态，每批每个句柄一次；空闲不启动计时器，不持续全量轮询。
4. 观察到 destroy 时，在任何新读取之前撤销旧身份；同进程同 HWND 再出现也分配新 Guid。延迟到达的显示/位置事件只触发重新检查，不重放事件里已经过时的几何，因此不能复活已关闭窗口。
5. 事件队列最多保留 2048 个不同 HWND。溢出表示可能丢了 destroy：撤销整个身份表并全量协调，宁可分配新 ID，也不继承不可靠的旧身份。失败批次合回队列；界面保留上次成功地图并提供手动重查入口。

COM 读取可能运行消息泵，使回调重入。处理前交换 pending 字典，把本批与新事件分离；新事件进入下批，读取失败时保留两批。通过专门测试确认不修改正在遍历的队列、不清掉刚到达的通知。

hook 委托由 GCHandle 保活，构造部分失败会清理已注册资源，窗口 Dispose 时在原 STA 线程 UnhookWinEvent。托管订阅者异常记录在 LastCallbackError 中，不跨原生回调边界传播。

## 真实地图与世界位置

`DesktopSpatialModel` 把准入快照投影到世界：`W = P - WorkArea.Position + PhysicalCameraPosition`。只读阶段 PhysicalCameraPosition 为零；预览相机单独导航，点击卡片或滚轮移动地图视角不会移动应用，也不会在下一次事件到来时改写其世界位置。

地图保留真实相对位置和尺寸，以同一比例绘制；前台窗口使用金色边框。新窗口、关闭、改名、用户移动和尺寸变化实时反映到卡片。比例在本次视图中保持，窗口移动不触发自动重新布局；点击“适配全部窗口”或控件尺寸变化时重新适配。未纳入的自身、系统、最小化、cloaked 和其他虚拟桌面窗口遵守 T01 策略。

后续控制器可在移动前登记目标窗口 Guid、预期物理矩形、递增 revision 和到期时间。完全匹配且仍有效的回调保留原世界位置；重复回调同样处理。位置不匹配、超时、取消、目标被排除/关闭都解除预期，外部拖动重新反投影到世界。当前只测试该识别协议，尚无真实跨进程批量移动事务；T06 必须单独验证部分移动失败与焦点行为。

Release 构建 0 警告、0 错误，61/61 模型检查、19/19 原生检查通过。新增 13 项模型检查覆盖增量身份、合并突发、同进程 HWND 复用、过时事件、顺序变化、失败重试、溢出失效、桌面重查、COM 重入、地图相机独立、自身预期回调与外部拖动、超时取消、关闭选择。

新增 7 项原生检查使用本进程透明窗口和真实 WinEvent 消息循环，覆盖 create/show、移动/尺寸/改名、子 HWND 排除、hide/show、destroy、12 个窗口快速创建关闭、回调异常隔离与释放后停止接收。测试只改变本程序测试窗口。

正常用户权限下的透明壳检查退出码为 0，扫描 309 项、2 项可纳入，真实地图显示 2 个窗口并正确保留重叠位置；已查看 PNG。沙箱因禁止读取外部进程身份而显示零候选的情况与正常权限结果分开记录。`artifacts/shell-smoke.json` 保存计数与监听状态，地图/候选截图可能包含标题，仅本地保留，不上传 Git。

虚拟桌面切换依赖 cloak/uncloak 及系统事件重新判断当前状态；对方未发送事件、权限不足、系统桌面/安全桌面切换存在通知边界，可手动重新检查。系统显示配置变化仍由 T11 验证。未声称已经完成真实平移、激活跟随或多屏兼容验收。
