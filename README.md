# Borderless Canvas

把 Windows 窗口放在一张可以上下左右移动的“大桌面”上。窗口太多时，移动视角找位置；想找某个窗口时，打开总览直接选择。

桌面背景和任务栏保持不动，软件窗口保持原来的大小。

## 获取源码与本地运行

本仓库目前提供源码，尚未发布可下载的 Release 或便携包。请在 Windows x64 上安装 .NET 10 SDK，然后运行：

```powershell
git clone https://github.com/BuanDesu/Borderless-Canvas.git
cd Borderless-Canvas
.\scripts\build.ps1
.\scripts\run.ps1
```

需要自行制作便携包时，参见[部署说明](docs/deployment.md)。下文的 `Start.cmd`、`Recover.cmd` 等入口适用于自行构建并完整解压的包。多显示器使用前，请把各屏的 Windows 缩放比例设为相同。

## 第一次使用

正常启动本软件后，画布会自动开始；没有打开窗口、或所有窗口都已最小化时也可以使用。已有的普通窗口和之后新开的普通窗口会自动加入。若本次运行中手动暂停，确认可以接管后点击“开始”恢复；若提示待恢复、设置或初始化问题，先按提示处理。

**把鼠标移到桌面空白处**，试着滚动滚轮：窗口会随视角移动。把鼠标移回应用窗口，就可以照常点击、输入和滚动页面。

| 想做什么 | 怎么操作 |
| --- | --- |
| 上下移动视角 | 在桌面空白处滚动滚轮 |
| 左右移动视角 | 按住 `Shift` 滚动滚轮 |
| 自由拖动视角 | 在桌面空白处同时按住鼠标左、右键拖动 |
| 查看所有窗口 | 在桌面空白处按 `Tab`；也可按 `Ctrl + Alt + O` |
| 快速切换窗口 | 在桌面空白处按住 `Ctrl` 滚动滚轮 |
| 回到开始的位置 | 在桌面空白处按 `Home` |
| 回到上一次移动前的位置 | 在桌面空白处按 `Backspace` |

滚轮和双键拖动在应用窗口内仍交给应用。桌面空白处单独右击，可以正常打开 Windows 右键菜单。要框选桌面图标时，先按 `Esc` 临时停止自动导航。

## 用总览找窗口、保存工作区

- **找窗口**：打开总览后，点击地图中的窗口即可前往；也可以在下方输入窗口标题查找。
- **返回**：再次按 `Tab`，或按 `Esc`，回到刚才的视角。
- **保存常用位置**：移动到喜欢的位置，打开总览，在下方工作区区域点击“+”保存。
- **切换工作区**：点击保存的卡片；右击卡片可以重命名或删除。

工作区保存的是观察位置。例如，把写作窗口放在左侧、资料窗口放在右侧，分别保存，就能随时跳转过去。

## 触控板和其他操作

| 功能 | 使用方法 |
| --- | --- |
| 触控板移动视角 | 按 `Ctrl + Alt + V` 开启触控导航，再用两指上下或左右滑动；单击、双击和拖动仍可操作应用。按 `Esc` 退出 |
| 固定一个窗口 | 先点击目标窗口，再按 `Ctrl + Alt + P`。它会固定在屏幕当前位置；再次按下可重新加入画布 |
| 准星模式 | 按 `Ctrl + Alt + C`，鼠标移动直接推动视角；按 `Esc` 退出后再操作应用 |
| 改快捷键和手势 | 打开主面板的“更多（⋯）→ 导航与键位设置” |

上述是默认快捷键；修改后以自己的设置为准。

## 暂停、退出和找回窗口

任务栏右下角有一个粉紫色小显示器图标，可能藏在“显示隐藏的图标”里。**双击图标打开主面板，右击图标打开菜单。**

- **暂停并恢复窗口**：在托盘菜单中选择此项，将受管理的窗口恢复到接管前的位置。
- **退出软件**：从托盘菜单选择“退出”。主面板右上角的关闭按钮只收起面板，画布仍会运行。
- **找不到窗口**：先用 `Ctrl + Alt + O` 打开总览查找；也可以从任务栏点击该应用。
- **异常退出后需要恢复**：重新启动，按提示进入恢复中心；也可以先退出管理器，再运行包内的 `Recover.cmd`。请保留待恢复记录，以便继续找回窗口。

## 常见问题

**浏览器的几个标签能分别摆放吗？** 先把标签拖出来，变成几个独立窗口，再放到画布上。

**为什么有些窗口没有加入？** 先将它恢复为普通窗口。最大化、全屏、置顶、管理员权限应用及部分特殊窗口目前有兼容限制。

**重新打开软件会恢复上次的布局吗？** 设置和保存的工作区会保留；窗口的画布布局目前只在本次运行中保留。

**怎样更新？** 先在旧版暂停并恢复窗口，再从托盘退出。确认原实例结束后，把新版完整解压到另一个新文件夹并启动，避免覆盖正在运行的文件。新版正常启动仍会自动开始画布，旧版退出前的暂停不代表新版默认暂停；保护边界见[部署说明](docs/deployment.md)。

目前是试用版，混合缩放比例多屏、更多特殊窗口和长期性能仍在完善。完整说明见[使用与恢复指南](docs/trial-guide.zh-CN.md)，问题可在 [Issues](https://github.com/BuanDesu/Borderless-Canvas/issues) 反馈；请先去掉窗口标题、个人路径和账号等私密信息。
